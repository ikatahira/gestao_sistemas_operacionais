🔵 Gerenciamento Completo de Arquivos

🔬 Laboratório ⏱ 30 min

📋 Enunciado

Execute uma série de operações de gerenciamento de arquivos simulando o trabalho real de organização de documentos de uma empresa.

📊 Rubrica de Avaliação

✅ Resolução Passo a Passo — Detalhada

1
Criar a estrutura base: C:\Empresa\

Abra o Explorador de Arquivos (Win+E), acesse o disco C:\ e crie a pasta Empresa. Dentro dela, crie as 4 subpastas. Clique com o botão direito → Novo → Pasta para cada uma:

📁 Estrutura esperada após o Passo 1
💡 Atalho rápido: Com a pasta Empresa aberta, pressione Ctrl+Shift+N para criar nova pasta sem usar o mouse.
2
Criar subpastas 2025 e 2026 dentro de cada departamento

Entre em cada uma das 4 pastas e crie as duas subpastas de ano. Repita o processo para RH, Financeiro, TI e Projetos:

📁 Estrutura esperada após o Passo 2
3
Criar pelo menos 3 arquivos de texto em cada subpasta com nomes descritivos

Dentro de cada subpasta (ex: RH\2025), clique com o botão direito → Novo → Documento de Texto. Use os nomes sugeridos abaixo:

📁 Financeiro \ 2026
📄 previsao_receita_2026.txt
📄 contratos_ativos.txt

📁 TI \ 2025

📄 chamados_suporte.txt

4
Mover 2 arquivos de RH\2025 para RH\2026

Abra a pasta C:\Empresa\RH\2025. Selecione 2 arquivos (ex: admissao_ana_silva.txt e ferias_equipe_2025.txt). Recorte e cole em RH\2026:

📁 RH\2025 — ANTES
📄 folha_pagamento_jan2025.txt
✂️ admissao_ana_silva.txt
✂️ ferias_equipe_2025.txt
Ctrl+X
→
Ctrl+V
📁 RH\2026 — DEPOIS
📄 metas_rh_2026.txt
📄 treinamento_jan2026.txt
📄 organograma_2026.txt
📥 admissao_ana_silva.txt
📥 ferias_equipe_2025.txt
⚠️ Mover ≠ Copiar! Após Ctrl+X + Ctrl+V, os arquivos somem da origem. Confirme que RH\2025 ficou só com 1 arquivo.
5
Copiar a pasta Financeiro\2025 para Financeiro\Backup

Primeiro crie a pasta Backup dentro de Financeiro. Depois, na pasta Financeiro, selecione a pasta 2025 inteira → Ctrl+C → abra Backup → Ctrl+V:

💡 A pasta 2025 original deve continuar existindo em Financeiro. O Backup é uma cópia independente — verifique que ambas existem.
6
Renomear arquivos de TI adicionando o prefixo ti_

Abra cada subpasta de TI. Clique uma vez no arquivo para selecioná-lo, pressione F2 para entrar no modo de edição e adicione ti_ no início do nome:

📁 TI\2025 — ANTES
📄 inventario_equipamentos.txt
📄 chamados_suporte.txt
📄 backup_servidores.txt
F2
→
+ prefixo
📁 TI\2025 — DEPOIS
📄 ti_inventario_equipamentos.txt
📄 ti_chamados_suporte.txt
📄 ti_backup_servidores.txt
💡 Repita para TI\2026 também. Selecione cada arquivo individualmente com F2 para preservar os nomes descritivos. Renomeação em lote (Ctrl+A + F2) cria nomes genéricos como ti_(1).txt.
7
Excluir a pasta Projetos → verificar na Lixeira → Restaurar

Este passo tem 3 sub-etapas obrigatórias:

a
Clique uma vez na pasta Projetos → pressione Delete. A pasta vai para a Lixeira — não desaparece permanentemente.
b
Abra a Lixeira no Desktop (duplo clique no ícone 🗑️). Confirme que a pasta Projetos aparece listada.
c
Clique com o botão direito na pasta Projetos → Restaurar. Ela volta para C:\Empresa\Projetos.
📸 Boa hora para o print! Tire um screenshot da Lixeira com a pasta Projetos visível — isso comprova que o passo foi executado.
8
Excluir definitivamente a pasta Projetos com Shift+Delete

Após restaurar no passo 7, selecione novamente a pasta Projetos e use Shift+Delete. Uma caixa de confirmação aparecerá:

🗑️ Excluir Pasta
⚠️

Tem certeza de que deseja excluir permanentemente a pasta Projetos e todo o seu conteúdo?

Sim
Não
🚨 Atenção: Após clicar em Sim, a pasta não vai para a Lixeira. Ela é removida permanentemente e não pode ser recuperada pelo Windows.
9
Documentar resultado final e salvar como sem06_ex1_SeuNome.docx

A estrutura final (sem a pasta Projetos) deve ser documentada com print do Explorador de Arquivos. Veja como deve ficar:

📁 Estrutura Final Esperada — C:\Empresa\
¹ RH\2025 ficou com apenas 1 arquivo  ·  ⁺ RH\2026 tem os arquivos originais + 2 vindos de 2025

Para documentar, abra o Word, cole os prints (Win+Shift+S para captura de área) e salve com o nome exato:

📄
sem06_ex1_SeuNome.docx
Exemplo: sem06_ex1_JoaoSilva.docx  ·  Use seu nome completo sem espaços

🔷 Configurando Permissões NTFS

🔬 Laboratório ⏱ 35 min

📋 Enunciado

Configure permissões NTFS em pastas simulando um ambiente corporativo com diferentes níveis de acesso para diferentes departamentos.

📊 Rubrica de Avaliação

✅ Resolução Passo a Passo

  1. ▸ Na pasta C:\Empresa\RH, clique direito → Propriedades → Segurança
  2. ▸ Observe os grupos e usuários que já têm permissões
  3. ▸ Clique em Editar → Adicionar → digite 'Todos' → OK
  4. ▸ Para o grupo 'Todos', configure: Leitura = Permitir, Gravação = Negar
  5. ▸ Isso simula: todos podem ver, mas não podem modificar os arquivos de RH
  6. ▸ Na pasta C:\Empresa\TI, dê Controle Total para seu usuário atual
  7. ▸ Tente criar um arquivo em RH — observe o erro de permissão negada
  8. ▸ Crie normalmente um arquivo em TI — funciona porque tem Controle Total
  9. ▸ Documente com prints e explique o que cada permissão faz. Salve: 'sem06_ex2_SeuNome.docx'

💡 Dica Profissional: Sempre documente o que você fez durante o laboratório. Um técnico sem registros não consegue reproduzir soluções nem comprovar seu trabalho.

🟢 Recuperação e Segurança de Dados

🔬 Laboratório ⏱ 25 min

Pratique técnicas de recuperação de arquivos da Lixeira e entenda as configurações de segurança para evitar perda acidental de dados.

✅ Resolução Passo a Passo

  1. ▸ Crie 5 arquivos de texto importantes com conteúdo relevante (simule documentos reais)
  2. ▸ Exclua todos os 5 arquivos normalmente (tecla Delete)
  3. ▸ Verifique: os arquivos estão na Lixeira? (duplo clique na Lixeira da área de trabalho)
  4. ▸ Restaure 3 dos 5 arquivos (clique direito → Restaurar)
  5. ▸ Verifique que os 2 não restaurados ainda estão na Lixeira
  6. ▸ Configure a Lixeira: clique direito na Lixeira → Propriedades → veja o tamanho máximo
  7. ▸ Altere o tamanho para 500 MB e documente
  8. ▸ Pesquise: existe algum software gratuito para recuperar arquivos deletados definitivamente?
