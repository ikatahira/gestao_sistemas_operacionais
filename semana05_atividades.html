Atividade 5 — Verdadeiro ou Falso

+40 XP
🎯

Conceitos de Gerenciamento de Arquivos

Julgue cada afirmação como Verdadeira (V) ou Falsa (F)

+40 XP
1O atalho Win + E abre o Explorador de Arquivos do Windows.
✅ Verdadeiro! Win + E é um dos atalhos mais úteis do Windows e abre o Explorador instantaneamente.
2Arquivos com atributo Oculto são deletados e ficam na Lixeira.
❌ Falso! Arquivos ocultos existem normalmente no disco. Eles apenas ficam invisíveis na listagem padrão. Para vê-los: Ver → Mostrar → Itens Ocultos.
3O formato AAAA-MM-DD é recomendado para nomear arquivos pois garante ordenação cronológica automática.
✅ Verdadeiro! Por exemplo: 2026-03-11_relatorio.docx. Como os arquivos se ordenam alfabeticamente, o formato do maior para o menor período garante a ordem cronológica.
4Arquivos com atributo Sistema podem ser modificados livremente sem risco algum.
❌ Falso! Arquivos de sistema são críticos para o Windows funcionar. Modificá-los sem saber o que está fazendo pode travar ou danificar o sistema operacional.
5O filtro tipo:*.pdf na barra de pesquisa do Explorador encontra apenas arquivos com extensão .pdf.
✅ Verdadeiro! O asterisco (*) é um curinga que representa qualquer nome. Então tipo:*.pdf encontra todo_arquivo.pdf, qualquer_nome.pdf, etc.
6É recomendável usar acentos e espaços nos nomes de pastas quando for trabalhar com programação.
❌ Falso! Acentos e espaços causam problemas em programação e linha de comando. Use underline (_) ou hífen (-). Ex: minha_pasta ou minha-pasta.
7Configurar as Opções de Indexação torna a pesquisa de arquivos muito mais rápida no Windows.
✅ Verdadeiro! A busca indexada é muito mais rápida pois o Windows já tem um mapa de onde está cada arquivo. Configure em: Painel de Controle → Opções de Indexação.
8Uma boa organização de pastas permite que um usuário desconhecido encontre qualquer arquivo em mais de 5 minutos.
❌ Falso! A regra de ouro é: uma pessoa que nunca viu seus arquivos deve conseguir encontrar qualquer coisa em menos de 30 segundos!
