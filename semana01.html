Fundamentos do Sistema Operacional

Imagine um restaurante. Você quer comer um prato. A cozinha tem todos os ingredientes (hardware). Mas alguém precisa organizar os pedidos e garantir que ninguém interfira no trabalho do outro. Esse gerente da cozinha é o Sistema Operacional.

O SO é o intermediário entre você e o hardware. Sem ele, você precisaria falar "binário" com o processador. Clique em cada função para entender:

O SO decide qual programa usa o processador a cada milissegundo. Esse mecanismo é chamado de escalonamento. Mesmo quando parece que tudo roda ao mesmo tempo, o processador alterna rapidíssimo entre as tarefas.
O SO distribui a memória RAM entre todos os processos. Cada programa tem sua área isolada — um não pode ler a memória do outro. Quando a RAM enche, o Windows cria o arquivo de paginação no disco (memória virtual).
Drivers são "tradutores" que permitem o SO se comunicar com dispositivos específicos como impressoras, webcams e placas de vídeo. Sem o driver correto, o dispositivo simplesmente não funciona no sistema.
O SO gerencia senhas de login, permissões de arquivos e usuários. Define quem pode acessar o quê, protegendo dados e isolando programas para evitar que um problema afete o sistema todo.

Os SOs se classificam pelo modo como lidam com tarefas e usuários. Conheça os 4 tipos — clique em cada um para expandir:

Monotarefa: executa apenas um programa por vez. Quando você abre um segundo, o primeiro é interrompido. Exemplo clássico: MS-DOS. Como um caixa de banco que atende um cliente de cada vez. Hoje raramente usado — ficou no passado.
Multitarefa: executa vários programas simultaneamente (o processador alterna entre eles muito rapidamente). É o que Windows, macOS e Linux fazem. Você ouve música, responde e-mail e navega ao mesmo tempo!

💡 Teste agora: pressione Ctrl + Shift + Esc para ver todos os processos rodando.
Multiusuário: permite que vários usuários usem o sistema ao mesmo tempo, cada um com seu perfil e permissões separadas. Muito comum em servidores de empresas e universidades. Linux e Windows Server são exemplos.
Multiprocessado: usa múltiplos processadores (ou núcleos) para processar tarefas mais rapidamente. Seu notebook provavelmente tem 4, 6 ou 8 núcleos — isso é multiprocessamento!

💡 Para ver seus núcleos: Win + R → msinfo32 → procure "Processador"

O Windows passou por décadas de evolução. Clique em cada era para expandir:

1985 — 1994
Windows 1.0 a 3.11 — Os primeiros passos
O Windows começou como uma "casca gráfica" sobre o MS-DOS. O Windows 1.0 era simples — apenas janelas básicas. O Windows 3.1 (1992) foi o primeiro realmente popular, com ícones e mouse funcionando bem. Ainda dependia totalmente do MS-DOS para funcionar.
1995 — 2000
Windows 95 a ME — A revolução visual
Windows 95 foi revolucionário: inventou o botão Iniciar, a barra de tarefas e o plug-and-play. Windows 98 melhorou a compatibilidade com a internet. O ME ficou famoso por ser instável. Curiosidade: o som de inicialização do Win95 foi composto pelo músico Brian Eno!
2001 — 2007
Windows XP a Vista — O clássico e o polêmico
O Windows XP (2001) é considerado o melhor Windows por muitos técnicos — estável, popular, durou mais de 12 anos no mercado! O Windows Vista (2007) tentou ser mais bonito mas exigia muito hardware e ficou com má reputação.
2009 — 2015
Windows 7 a 10 — A recuperação e modernização
O Windows 7 "consertou" os erros do Vista e voltou a ser amado. Windows 8 foi polêmico por remover o botão Iniciar. O Windows 8.1 corrigiu isso. Windows 10 (2015) trouxe de volta o Iniciar e integração com nuvem. Suporte ao Win 10 encerrou em outubro de 2025!
2021 — atual
Windows 11 — O Windows atual
Redesenhou a interface: botão Iniciar centralizado, novo menu Iniciar, Snap Layouts para organizar janelas, e requisitos mais altos (exige TPM 2.0). É o Windows dos notebooks novos. Como técnico, você precisa dominar o Win 11!
