🔐 1. Permissões NTFS +20 XP ▼

O sistema NTFS permite controlar quem pode fazer o quê com cada arquivo ou pasta.

👁️
Leitura: pode ver o conteúdo, mas não modificar.
✏️
Gravação: pode modificar o conteúdo do arquivo.
▶️
Execução: pode rodar o programa (arquivos .exe, .bat).
👑
Controle Total: pode fazer absolutamente tudo, inclusive alterar as permissões.
🔧

Como configurar: clique direito → Propriedades → aba Segurança → Editar. Em empresas, o admin gerencia isso via Active Directory.

📋 2. Copiar vs. Mover — Qual a diferença? +20 XP ▼

Essa é uma das dúvidas mais comuns! A diferença é simples mas importante:

📄
COPIAR (Ctrl+C → Ctrl+V): cria uma segunda cópia — o original permanece no lugar!
✂️
MOVER (Ctrl+X → Ctrl+V): transfere o arquivo — o original SOME do local de origem.
🖱️
Arrastar entre pastas NO MESMO DISCO = Mover. Arrastar entre discos diferentes = Copiar.
✏️
Renomear: pressione F2 ou faça um clique lento (não duplo!) no nome do arquivo.
Ctrl+CCopiar
Ctrl+XRecortar
Ctrl+VColar
F2Renomear

🗑️ 3. Lixeira — Sua Rede de Segurança +20 XP ▼

A Lixeira é sua segunda chance! Mas tem regras importantes:

✅
Arquivos excluídos do disco local vão para a Lixeira — você pode restaurá-los!
⚠️
Arquivos excluídos de pendrive ou rede são deletados PERMANENTEMENTE — sem Lixeira!
💀
Shift + Delete exclui definitivamente sem passar pela Lixeira. Use com cuidado!
📦
A Lixeira tem tamanho limitado (configurável). Quando cheia, os arquivos mais antigos são deletados permanentemente.
⚠️

Regra de ouro: Sempre verifique a Lixeira antes de dizer que um arquivo "sumiu"!

⚡ 4. Operações em Lote +20 XP ▼

Selecionar e operar em múltiplos arquivos de uma vez economiza horas de trabalho!

🖱️
Ctrl + clique: seleciona arquivos individuais (não precisa ser em sequência).
↕️
Shift + clique: seleciona todos os arquivos entre o primeiro e o último clicado.
☑️
Ctrl + A: seleciona TODOS os arquivos da pasta de uma vez.
📦
Com vários arquivos selecionados, você pode copiar, mover, excluir ou comprimir todos de uma vez!
Ctrl+ASelecionar tudo
Ctrl+cliqueSeleção individual
Shift+cliqueSelecionar intervalo
🚀

Desafio: Renomeie 10 arquivos de uma vez! Selecione todos com Ctrl+A, pressione F2, e digite um nome — o Windows numera automaticamente!
