🔬 Laboratório ⏱ 20 min

📋 Enunciado

Crie um script de manutenção preventiva que limpa arquivos temporários e otimiza o sistema.

✅ Resolução Passo a Passo

  1. ▸ # Script de limpeza — execute apenas como Administrador
  2. ▸ function Remove-TemporaryFiles {
  3. ▸ $pastas = @($env:TEMP, 'C:\Windows\Temp')
  4. ▸ $totalLimpo = 0
  5. ▸ foreach ($pasta in $pastas) {
  6. ▸ $arquivos = Get-ChildItem $pasta -Recurse -ErrorAction SilentlyContinue
  7. ▸ $totalLimpo += ($arquivos | Measure-Object -Property Length -Sum).Sum
  8. ▸ Remove-Item "$pasta\*" -Recurse -Force -ErrorAction SilentlyContinue
  9. ▸ Write-Host "Limpo: $pasta" -ForegroundColor Green
  10. ▸ }
  11. ▸ $mbLimpos = [math]::Round($totalLimpo/1MB, 2)
  12. ▸ Write-Host "Total liberado: $mbLimpos MB" -ForegroundColor Cyan
  13. ▸ }
  14. ▸ Remove-TemporaryFiles
  15. ▸ Salve: 'sem12_ex2_SeuNome.ps1'
