💻 1. O que é o PowerShell? +20 XP ▼

PowerShell é uma linguagem de script e shell desenvolvida pela Microsoft. É a ferramenta padrão para automação no mundo Windows!

🔄
Diferente do Prompt de Comando (cmd) antigo, o PowerShell é orientado a objetos — trabalha com objetos .NET, não apenas texto.
☁️
É a ferramenta padrão para gerenciar Windows, Azure e Microsoft 365. Todo admin de TI precisa saber!
🌍
PowerShell 7+ é multiplataforma — funciona no Windows, Linux e macOS! (instale separado do 5.1 nativo)
🚀

Para abrir: Win + X → Terminal do Windows. Ou pesquise "PowerShell" no menu Iniciar. Dica: abra sempre como Administrador para ter acesso total!

🎯 2. Por que PowerShell importa? +20 XP ▼

Com PowerShell você transforma trabalho de horas em segundos:

📁
Renomear 1000 arquivos seguindo um padrão? 1 linha de código.
👥
Criar 50 usuários no Active Directory de uma vez? 1 script de 5 linhas.
🖥️
Verificar status de serviços em 100 computadores remotamente? Alguns cmdlets.
📊
Gerar relatórios do sistema e exportar para Excel? Uma linha com Export-Csv!
💡

Pense assim: quem não sabe PowerShell faz manualmente. Quem sabe PowerShell automatiza. No mercado de TI, isso faz toda a diferença no salário!

📝 3. Estrutura dos Cmdlets: Verbo-Substantivo +20 XP ▼

Todo comando PowerShell segue o padrão Verbo-Substantivo. É consistente e fácil de memorizar!

🟢
Get = obter/listar: Get-Process, Get-Service
🔵
Set = definir/alterar: Set-Location, Set-Content
🟣
New = criar: New-Item, New-LocalUser
🔴
Remove = remover: Remove-Item, Remove-Service
🟡
Start/Stop = iniciar/parar: Start-Service, Stop-Process
💡

Truque: Se não sabe o nome exato, use Get-Command *palavra* para buscar comandos que contenham aquela palavra!

⚙️ 4. Configurando o PowerShell +20 XP ▼

Antes de começar a usar, algumas configurações importantes:

🛡️
Política de Execução: por padrão, scripts são bloqueados por segurança. Veja a política atual: Get-ExecutionPolicy
🔓
Para desenvolvimento: Set-ExecutionPolicy RemoteSigned. Permite seus scripts, mas bloqueia scripts não assinados da internet.
❓
Ajuda integrada: Get-Help Get-Process mostra a documentação de qualquer comando!
📋
Tab completion: comece a digitar um comando e pressione Tab — o PowerShell completa automaticamente!
⚠️

Em produção, mantenha a política mais restritiva possível. Só libere o necessário!
