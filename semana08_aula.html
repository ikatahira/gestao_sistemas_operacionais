💻 1. O que é o PowerShell? +20 XP ▼

PowerShell é a linha de comando moderna do Windows. Em vez de usar o mouse para clicar em menus, você digita comandos que fazem o computador trabalhar para você.

🤔
Por que aprender isso? Tarefas que levariam 1 hora clicando em menus, levam 5 segundos com um comando. É como ter um controle remoto ultra-poderoso do Windows.
🔄
PowerShell vs CMD antigo: O CMD (prompt de comando) é de 1987. O PowerShell é moderno, mais poderoso e é o que o mercado de TI usa hoje.
🌍
PowerShell 7+ funciona também no Linux e macOS — útil quando você trabalhar em ambientes mistos.
💡

Analogia: O PowerShell é como aprender a falar com o computador em vez de ficar apontando para as coisas. No começo parece difícil, mas depois é muito mais rápido!

Exemplos reais do que você vai conseguir fazer:

📁
Renomear 500 arquivos de uma vez — em vez de um por um
👥
Ver todos os programas instalados em um computador em segundos
🔍
Descobrir qual processo está travando o computador

📝 3. Estrutura dos Cmdlets: Verbo-Substantivo +20 XP ▼

Todo comando PowerShell (chamado de cmdlet) segue um padrão lógico: Verbo + Substantivo

Ou seja: o que fazer + com o quê fazer.

Get-Process

Obter  +  Processos  =  lista os processos em execução

🟢
Get = obter/listar: Get-Process   Get-Service   Get-ChildItem
🔵
Set = definir/alterar: Set-Location   Set-Content
🟣
New = criar: New-Item   New-LocalUser
🔴
Remove = remover: Remove-Item   Remove-Service
🟡
Start/Stop = iniciar/parar: Start-Service   Stop-Process
💡

Truque ninja: Se não sabe o nome exato do comando, use Get-Command *palavra* para buscar! Exemplo: Get-Command *process* lista tudo relacionado a processo.

📊 Comparando PowerShell com o CMD antigo:

Mostrar pasta atualcdGet-Location
Navegar para uma pastacd C:\Set-Location C:\
Limpar a telaclsClear-Host
Criar pastamkdir NomePastaNew-Item -Type Directory
💡

Os aliases do CMD ainda funcionam no PowerShell! Digitar dir ou cd continua funcionando. Mas aprenda os nomes reais para ser profissional.

⌨️ 4. Seus Primeiros Comandos — Mãos na Massa! +20 XP ▼

Com o PowerShell aberto como administrador, vamos executar comandos! Você digita o comando e aperta Enter.

📌 Como digitar corretamente: Os comandos são sensíveis ao hífen ( - ) e às letras maiúsculas/minúsculas no nome do cmdlet. Copie exatamente como mostrado!

Comando 1 Ver a data e hora atual

O que fazer: Digite o comando abaixo e pressione Enter

Administrador: Windows PowerShell
PS C:\Windows\System32> Get-Date
  segunda-feira, 27 de abril de 2026 08:45:32  
PS C:\Windows\System32>
📌

A data e hora do seu computador aparecem. O formato pode ser diferente dependendo das configurações do Windows.

Comando 2 Ver os programas abertos (processos)

O que fazer: Digite e pressione Enter:

Administrador: Windows PowerShell
PS C:\Windows\System32> Get-Process
  Handles NPM(K) PM(K) WS(K) CPU(s) Id SI ProcessName ------- ------ ----- ----- ------ -- -- ----------- 356 22 5624 18432 0,47 1820 1 chrome 124 14 3104 8904 0,12 2340 1 explorer 289 18 4832 12288 1,23 3560 1 msedge 445 31 8192 24576 2,81 4120 1 powershell ... (muitas linhas vão aparecer) ...  
PS C:\Windows\System32>
📌

Uma lista de todos os processos (programas) rodando aparece. Handles = recursos usados, CPU(s) = uso do processador, ProcessName = nome do programa.

Comando 3 Ver a versão do PowerShell instalada

O que fazer: Digite (atenção ao $ no começo!) e pressione Enter:

Administrador: Windows PowerShell
PS C:\Windows\System32> $PSVersionTable
  Name Value ---- ----- PSVersion 5.1.22621.4391 PSEdition Desktop PSCompatibleVersions {1.0, 2.0, 3.0, 4.0...} BuildVersion 10.0.22621.4391 CLRVersion 4.0.30319.42000 WSManStackVersion 3.0 PSRemotingProtocolVersion 2.3 SerializationVersion 1.1.0.1

PSVersion 5.1 = versão nativa do Windows 11. Se aparecer 7.x, você tem o PowerShell 7 instalado (mais moderno). Ambas funcionam para esta aula!

Comando 4 Ver os serviços do Windows

O que fazer: Digite e pressione Enter:

⚙️ 5. Configurando o PowerShell — Política de Execução +20 XP ▼

Antes de executar scripts (arquivos .ps1), o Windows bloqueia por segurança. Vamos verificar e ajustar essa configuração.

⚠️ O que é a Política de Execução? É uma proteção do Windows que impede scripts não autorizados de rodar. Para as nossas aulas, precisamos liberar um pouco.

📋 Passo 1 — Verificar a política atual
Administrador: Windows PowerShell
PS C:\Windows\System32> Get-ExecutionPolicy
  Restricted  
PS C:\Windows\System32>
📌

Restricted = bloqueado (não deixa rodar nenhum script). Se aparecer isso, faça o Passo 2. Se aparecer RemoteSigned, pode pular o Passo 2.

🔓 Passo 2 — Liberar scripts para estudo

Digite o comando abaixo exatamente assim (precisa estar como Administrador!):

Administrador: Windows PowerShell
PS C:\Windows\System32> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  Alteração na política de execução A política de execução ajuda a proteger você de scripts nos quais não confia. Deseja alterar a política de execução? [S] Sim [A] Sim para Todos [N] Não [T] Não para Todos [?] Ajuda
(padrão é "N"): S
 
PS C:\Windows\System32>
📌

Quando perguntar, digite S e pressione Enter para confirmar. Isso libera seus próprios scripts, mas ainda bloqueia scripts suspeitos da internet.

⚠️

Em computadores da escola: pode ser que a política já esteja configurada pelo administrador. Se aparecer erro de permissão, chame o professor — não é sua conta de admin.

❓ Bônus — Como pedir ajuda dentro do PowerShell

Não lembra o que um comando faz? Use o manual embutido:

Administrador: Windows PowerShell
PS C:\Windows\System32> Get-Help Get-Process
  NOME Get-Process   SINOPSE Obtém os processos em execução no computador local.   SINTAXE Get-Process [[-Name] <String[]>] [...] ... (continua) ...
PS C:\Windows\System32>
💡

Quer ver exemplos práticos? Use Get-Help Get-Process -Examples. Sempre que travar, consulte o help!
