SEÇÃO A — Introdução ao SO & Arquitetura Interna Q01–Q08 · 40 pts
Q01 Qual é a principal função de um Sistema Operacional? Conceito SO
A)Criar documentos e planilhas
B)Intermediar a comunicação entre o usuário e o hardware✅
C)Conectar o computador à internet
D)Processar imagens e vídeos
💡 Por quê B? O SO gerencia CPU, RAM, armazenamento e periféricos — ele é o "gerente" entre você e o hardware. Sem ele, nenhum programa funcionaria.
Q02 Qual dos itens abaixo NÃO é um Sistema Operacional? Tipos de SO
A)Windows 11
B)Android
C)Microsoft Word✅
D)macOS
💡 Por quê C? O Word é um aplicativo que roda dentro de um SO. Sistemas Operacionais: Windows, Android, macOS, Linux. O Word precisa do SO para existir.
Q03 O que acontece quando ocorre um erro crítico no Kernel Mode do Windows? Kernel Mode
A)Apenas o aplicativo com erro é encerrado
B)O sistema exibe a Tela Azul da Morte (BSOD) e trava✅
C)O Windows reinicia automaticamente sem aviso
D)O User Mode assume o controle do hardware
💡 Por quê B? Erro no Kernel = sistema inteiro trava com a BSOD. O Kernel tem acesso total ao hardware — sem ele, nada funciona. Por isso o erro é catastrófico.
Q04 Por que o Chrome não derruba o Windows quando trava? User Mode
A)Porque o Chrome é muito bem programado
B)Porque roda em User Mode, isolado do Kernel✅
C)Porque o Windows o protege especialmente
D)Porque o Chrome tem acesso direto ao hardware
💡 Por quê B? Aplicativos rodam em User Mode com acesso restrito. Se travarem, o Kernel os encerra sem afetar o resto do sistema. É a "sandboxing" do SO.
Q05 O PID de um processo é: Processos
A)O percentual de CPU que o processo consome
B)Um número único que identifica cada processo em execução✅
C)O tamanho em MB que o processo ocupa na RAM
D)O nome do arquivo executável do programa
💡 PID = Process ID. Cada processo em execução recebe um número único. Você pode ver na aba Detalhes do Gerenciador de Tarefas (Ctrl+Shift+Esc).
Q06 Um processo aguardando resposta da rede se encontra em qual estado? Estados
A)Executando
B)Pronto
C)Bloqueado / Aguardando✅
D)Suspenso pelo Kernel
💡 Processo aguardando evento externo (rede, disco, input do usuário) = Bloqueado. Ele não consome CPU enquanto espera — o Kernel o "pausa" e usa a CPU para outras tarefas.
Q07 Quando a RAM está cheia, o Windows utiliza: Memória Virtual
A)O processador como memória temporária
B)A placa de vídeo para armazenar dados
C)Memória virtual (arquivo de paginação no disco)✅
D)A memória cache do processador
💡 Quando a RAM enche, o SO usa um arquivo de paginação (pagefile.sys) no HD/SSD como extensão da memória. É muito mais lento que a RAM, mas evita travamentos.
Q08 Qual atalho abre o Gerenciador de Tarefas diretamente? Gerenciador
A)Ctrl + Alt + Del
B)Ctrl + Shift + Esc✅
C)Win + R
D)Alt + F4
💡 Ctrl+Shift+Esc abre o Gerenciador diretamente. O Ctrl+Alt+Del abre um menu intermediário onde você ainda precisa clicar. Na prova prática, use o atalho direto!
SEÇÃO B — Interface & Atalhos do Windows 11 Q09–Q16 · 40 pts
Q09 No Windows 11, o Botão Iniciar fica por padrão em qual posição? Barra de Tarefas
A)Canto inferior esquerdo (como no Windows 10)
B)Centralizado na barra de tarefas✅
C)Canto superior direito
D)Canto inferior direito
💡 O Win 11 centralizou o Iniciar — uma das maiores mudanças visuais da versão. Pode ser movido de volta para a esquerda em Configurações → Personalização → Barra de Tarefas.
Q10 Como ativar o Snap Layouts no Windows 11? Snap Layouts
A)Clicar duas vezes na barra de título
B)Passar o mouse sobre o botão Maximizar (⬜) da janela✅
C)Clicar com o botão direito na área de trabalho
D)Acessar Painel de Controle → Exibição
💡 Passe o mouse sobre o ⬜ (botão Maximizar) — o menu de Snap Layouts aparece. Você também pode usar Win + ←/→ ou Win + Z para abrir direto o menu.
Q11 O atalho Win + D realiza qual ação? Win + D
A)Abre as Configurações do Windows
B)Mostra/oculta a área de trabalho✅
C)Abre o Explorador de Arquivos
D)Divide a janela à direita
💡 Win+D minimiza todas as janelas mostrando a área de trabalho. Pressionar novamente restaura tudo. Útil para acessar ícones da área de trabalho rapidamente.
Q12 Qual atalho encaixa a janela na metade esquerda da tela? Snap Esquerda
A)Win + ↑
B)Win + →
C)Win + ←✅
D)Alt + Tab
💡 Mapa dos atalhos de Snap: Win+← = esquerda · Win+→ = direita · Win+↑ = maximiza · Win+↓ = minimiza. Esta foi a resposta certa da Tarefa 02 da prova prática!
Q13 Onde ficam Wi-Fi, Bluetooth e Brilho no Windows 11? Central de Ações
A)Central de Notificações (ícone de sino)
B)Central de Ações (ícone de rede/volume/bateria)✅
C)Menu Iniciar → Configurações Rápidas
D)Painel de Widgets (Win + W)
💡 No Win 11, notificações e ações rápidas foram separadas. Wi-Fi, Bluetooth e brilho ficam na Central de Ações (clique nos ícones de rede/volume/bateria no canto direito da barra).
Q14 Diferença entre conta Administrador e Usuário Padrão? Contas
A)Não há diferença — ambas têm os mesmos privilégios
B)Administrador instala software e altera o sistema; Usuário Padrão tem acesso restrito✅
C)Usuário Padrão pode instalar programas, mas não alterar data/hora
D)A conta Administrador só existe em versões corporativas
💡 Administrador tem controle total do sistema. Usuário Padrão é mais seguro para o uso cotidiano (menos risco de vírus ou alterações acidentais). Use Padrão no dia a dia e Administrador apenas quando necessário.
Q15 Para ver todos os apps instalados no Menu Iniciar do Win 11: Menu Iniciar
A)Clicar com o botão direito na área de trabalho
B)Clicar em "Todos os apps" dentro do Menu Iniciar✅
C)Acessar o Painel de Controle → Programas
D)Pressionar Win + R e digitar "appwiz.cpl"
💡 No Win 11, o Iniciar mostra apps fixados por padrão. O botão "Todos os apps" no canto superior direito do Iniciar lista todos os instalados em ordem alfabética.
Q16 Como adicionar o ícone "Este Computador" na área de trabalho? Ícones
A)Clicar direito na Área de Trabalho → Novo → Atalho
B)Clicar direito → Personalizar → Temas → Configurações de ícones da área de trabalho✅
C)Abrir o Explorador de Arquivos e arrastar "Este PC"
D)Painel de Controle → Sistema → Ícones
💡 Caminho completo: Área de Trabalho (botão direito) → Personalizar → Temas → Configurações de ícones da área de trabalho → marcar "Computador".
SEÇÃO C — Gerenciamento de Arquivos & Pastas Q17–Q20 · 20 pts
Q17 Qual atalho abre o Explorador de Arquivos instantaneamente? Explorador
A)Win + E✅
B)Win + X
C)Ctrl + E
D)Alt + F2
💡 Win+E = Explorador de Arquivos. Atalho essencial para técnicos — você usou na Tarefa 03 da prova prática! Win+X abre o menu de ferramentas do sistema.
Q18 Um arquivo com atributo Sistema (System) indica que: Atributos
A)O arquivo está marcado para backup
B)O arquivo não aparece na listagem normal
C)É um arquivo crítico do SO — não deve ser modificado✅
D)O arquivo só pode ser lido, nunca executado
💡 Atributo Sistema = arquivo usado pelo Windows para funcionar (ex: ntldr, pagefile.sys). Modificar ou apagar pode tornar o SO instável ou impedir o boot. Atenção: não confunda com atributo Oculto.
Q19 Ao arrastar um arquivo entre pastas do mesmo disco, o que ocorre? Copiar vs Mover
A)O arquivo é copiado — o original permanece no lugar
B)O arquivo é movido — o original some da origem✅
C)O arquivo é comprimido automaticamente
D)O Windows solicita confirmação
💡 Regras de drag & drop: mesmo disco = Move · discos diferentes = Copia · segurando Ctrl = sempre Copia · Shift = sempre Move. Na Tarefa 03 você fez uma cópia com Ctrl+C/Ctrl+V justamente para preservar o original.
Q20 Qual afirmação sobre a Lixeira está correta? Lixeira & NTFS
A)Arquivos excluídos de pendrive também vão para a Lixeira
B)Shift + Delete exclui sem passar pela Lixeira✅
C)A Lixeira tem espaço ilimitado no disco
D)Arquivos excluídos da rede ficam na Lixeira por 30 dias
💡 Por que as outras estão erradas: A) Pendrive/rede → sem Lixeira (exclusão imediata) · C) Lixeira tem tamanho limitado configurável · D) Arquivos de rede são excluídos permanentemente. Shift+Delete = exclusão permanente — use com cuidado!

TAREFA 01 Identificando o Sistema e os Processos 30 pts · Seção A
Cenário: você foi contratado como estagiário de TI e precisa levantar as informações básicas do computador e os processos em execução.
  • 1
    Pressione Win + R, digite msinfo32 e confirme.
    ✅ O que anotar: Nome do SO (ex: Windows 11 Home 23H2), Versão do Windows (número de build) e Fabricante do processador (Intel/AMD). Tudo está na tela inicial do System Information.
  • 2
    Abra o Gerenciador de Tarefas com Ctrl + Shift + Esc. Na aba Desempenho, anote CPU e RAM.
    ✅ O que anotar: Percentual de uso de CPU (ex: "12%") e RAM em uso (ex: "4,2 GB / 8,0 GB"). Os números variam — o que conta é estar na aba certa e anotar os dois.
  • 3
    Na aba Detalhes, identifique 3 processos que você reconhece.
    ✅ Exemplos válidos: chrome.exe (PID qualquer), explorer.exe, notepad.exe, taskmgr.exe, Code.exe, Teams.exe. Anote o nome exato e o PID (número na coluna ao lado).
    ⚠️ Erro comum: anotar processos de sistema que você "não reconhece" (ex: svchost.exe). O enunciado pede processos que você reconhece — use os de aplicativos abertos no momento.
  • 4
    Tire um print da aba Detalhes com Win + Shift + S e cole no documento.
    ✅ Critério de qualidade: print deve mostrar claramente as colunas Nome e PID. Recorte em tela inteira também é aceito. Cole diretamente no documento Word com Ctrl+V.

TAREFA 02 Organizando Janelas com Snap Layouts 30 pts · Seção B
Cenário: um usuário de suporte precisa ver ao mesmo tempo o Explorador de Arquivos, o Bloco de Notas e o Gerenciador de Tarefas.
  • 1
    Abra as 3 janelas: Explorador (Win+E), Bloco de Notas e Gerenciador de Tarefas (Ctrl+Shift+Esc).
    ✅ Use os atalhos para abrir cada uma. O Bloco de Notas pode ser aberto pelo Iniciar (pesquise "Notepad") ou Win+R → notepad.
  • 2
    Use o Snap Layouts — passe o mouse sobre ⬜ (Maximizar) — para organizar as 3 janelas lado a lado.
    ✅ Layout recomendado: escolha o grid 3 colunas ou 1 grande + 2 pequenas. Não redimensione manualmente — o enunciado exige o Snap Layouts.
    ⚠️ Erro comum: organizar manualmente arrastando as bordas das janelas. Isso não usa o Snap Layouts e perde pontos no critério "Snap Layout utilizado".
  • 3
    Tire um print com as 3 janelas organizadas e cole no documento.
    ✅ Print deve mostrar claramente as 3 janelas ao mesmo tempo na tela, organizadas pelo Snap — sem sobreposição.
  • 4
    Responda por escrito: "Qual atalho encaixa uma janela na metade esquerda da tela?"
    ✅ Resposta correta: Win + ← (seta esquerda). Esta é a mesma resposta da Q12 da prova teórica! Quem acertou lá, deve ter acertado aqui também.

TAREFA 03 Criando a Estrutura de Arquivos de uma Empresa 25 pts · Seção C
Cenário: você foi designado para organizar os arquivos de uma pequena empresa no computador local, seguindo boas práticas de nomenclatura e hierarquia profissional.
  • 1
    Crie a estrutura em C:\AvaliacaoPratica\ com subpastas RH\, TI\ e Backup\.
    ✅ Use Win+E → navegue até C:\ → Ctrl+Shift+N para cada pasta. Crie primeiro AvaliacaoPratica, depois entre nela e crie as três subpastas.
    ⚠️ Atenção ao nome: AvaliacaoPratica sem acentos e com letras maiúsculas conforme o enunciado. Mas os arquivos dentro devem seguir a regra: só minúsculas e underline.
  • 2
    Crie os arquivos .txt dentro de RH\ e TI\ com os nomes corretos.
    ✅ Arquivos em RH\: contrato_joao_silva.txt, ferias_2026.txt, admissao_2026.txt
    Arquivos em TI\: inventario_equipamentos.txt, chamados_suporte.txt
    Clique direito → Novo → Documento de Texto. Renomeie imediatamente removendo o ".txt" se necessário.
    ⚠️ Erros comuns de nomenclatura: usar espaços (contrato joao.txt), acentos (férias.txt) ou maiúsculas (Contrato.txt). Todos descontam pontos.
  • 3
    Copie (Ctrl+C + Ctrl+V) a pasta RH\ inteira para dentro de Backup\.
    ✅ Selecione a pasta RH (clique uma vez), Ctrl+C, abra Backup\, Ctrl+V. Confirme que a RH\ original ainda existe em AvaliacaoPratica\ — o enunciado pede que o original seja preservado.
  • 4
    Renomeie (F2) o arquivo chamados_suporte.txt para 2026-04_chamados_suporte.txt.
    ✅ Clique uma vez no arquivo → pressione F2 → edite o nome adicionando 2026-04_ no início → Enter. O hífen é parte do nome — não use underline aqui.
  • 5
    Tire um print do Explorador mostrando a estrutura completa.
    ✅ Expanda todas as pastas no painel esquerdo do Explorador para mostrar a hierarquia completa. O print deve mostrar AvaliacaoPratica → RH, TI, Backup → RH e os arquivos.

TAREFA 04 Investigando Atributos e Exclusão Segura 15 pts · Seção D
Cenário: como técnico, você precisa proteger um arquivo importante de edições acidentais e entender como funciona a exclusão segura.
  • 1–2
    Abra contrato_joao_silva.txt, tente editar, salve. Depois marque como "Somente leitura" (botão direito → Propriedades → atributo Somente leitura → OK).
    ✅ O atributo Somente leitura fica na aba Geral das Propriedades, no rodapé "Atributos". Marque a caixa e clique OK.
  • 3
    Tente editar e salvar novamente o arquivo marcado. Anote a mensagem de erro.
    ✅ Mensagem esperada: "Acesso negado" ou "O arquivo é somente leitura. Deseja salvar em outro lugar?" (o Bloco de Notas pergunta onde salvar). Ambas as respostas são aceitas.
    ⚠️ Se o Bloco de Notas perguntou "Salvar como?", isso também conta! Anote o que apareceu na sua tela.
  • 4
    Exclua ferias_2026.txt com a tecla Delete. Abra a Lixeira e restaure o arquivo. Verifique que voltou para RH\.
    ✅ Na Lixeira: clique direito no arquivo → Restaurar. O arquivo voltará automaticamente para a pasta original C:\AvaliacaoPratica\RH\. Verifique no Explorador.
    ⚠️ Se você usou Shift+Delete acidentalmente, o arquivo foi excluído permanentemente (sem Lixeira). Nesse caso, crie o arquivo novamente e repita o processo com Delete simples.
  • 5
    Tire um print das Propriedades do arquivo com atributo "Somente leitura" marcado.
    ✅ O print deve mostrar a caixa "Somente leitura" marcada na janela Propriedades do arquivo. Certifique-se de que o nome do arquivo aparece no título da janela.

Erros Mais Comuns

Estes foram os padrões de erro mais observados. Se você errou algum deles, leia a explicação e grave a correção para as próximas avaliações.

📝

Prova Teórica — Q03: Confundir erro de aplicativo com erro de Kernel

Muitos marcaram A) "Apenas o aplicativo com erro é encerrado". Isso acontece com erros em User Mode — quando o Chrome trava, por exemplo. Erro no Kernel Mode é diferente: afeta o sistema inteiro e gera BSOD.

✅ Lembrete: Kernel = sistema inteiro · User Mode = só o app
🔀

Prova Teórica — Q19: Arrastar = Mover (mesmo disco)

Muitos marcaram A) "o arquivo é copiado". A confusão é natural, mas no Windows arrastar entre pastas do mesmo disco move o arquivo. Arrastar entre discos diferentes copia.

✅ Segure Ctrl ao arrastar para SEMPRE copiar, independente do disco
🏷️

Prova Prática — Tarefa 03: Erros de nomenclatura nos arquivos

Arquivos criados com espaços (contrato joao silva.txt), acentos (férias_2026.txt) ou letras maiúsculas (Contrato_Joao.txt). A regra é clara: só minúsculas, underline e sem acentos.

✅ Padrão correto: contrato_joao_silva.txt (snake_case)
📐

Prova Prática — Tarefa 02: Organizar janelas manualmente em vez de usar Snap Layouts

Arrastar as bordas das janelas para organizar parece funcionar, mas o enunciado exige especificamente o uso do Snap Layouts (menu que aparece ao passar o mouse sobre o botão Maximizar). Organizar à mão não atende ao critério.

✅ Sempre use o ícone ⬜ (Maximizar) para acessar o Snap Layouts
🗑️

Prova Prática — Tarefa 04: Usar Shift+Delete acidentalmente

Alguns alunos usaram Shift+Delete no passo de exclusão, o que remove o arquivo permanentemente sem passar pela Lixeira. O exercício pede exclusão comum (Delete) justamente para demonstrar a função de restauro.

✅ Delete simples → Lixeira · Shift+Delete → exclusão permanente (sem volta!)
🖼️

Geral: Prints fora do contexto ou de baixa qualidade

Prints muito pequenos, cortados ou sem mostrar as informações pedidas. Lembre-se: o print é a evidência de que você executou a tarefa. Se não aparecer claramente, não conta.

✅ Use Win+Shift+S para recorte de tela com qualidade e cole direto no Word

Kernel vs User Mode
Kernel Mode: acesso total ao hardware. Erro = BSOD (tela azul). Exemplos: drivers, serviços do SO.

User Mode: acesso restrito. Erro = só o app fecha. Exemplos: Chrome, Word, Bloco de Notas.

Isso explica por que apps podem travar sem derrubar o Windows.
