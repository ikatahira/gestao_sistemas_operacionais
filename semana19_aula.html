Na semana passada: Inicialização e Solução de Problemas

Você aprendeu a diagnosticar e resolver problemas de boot com msconfig, Modo Seguro, WinRE e comandos como sfc /scannow e bootrec. Hoje o foco muda: em vez de resolver problemas técnicos do sistema, vamos configurar o Windows para resolver problemas de pessoas — adaptando o computador para diferentes necessidades.

msconfig sfc /scannow bootrec /fixmbr WinRE bcdedit
💡
Conexão com hoje: Assim como o Modo Seguro simplifica o ambiente para diagnóstico, as ferramentas de acessibilidade simplificam ou adaptam o ambiente para que qualquer pessoa consiga usar o computador com efetividade.

♿ Por que Acessibilidade é Importante para um Técnico?

Como técnico em TI, você vai configurar computadores para pessoas reais com necessidades diferentes. Acessibilidade não é tema de "especialista" — é uma competência obrigatória de quem configura sistemas.

Lei nº 13.146/2015 · ABNT NBR 17060:2022
Lei Brasileira de Inclusão (Estatuto da Pessoa com Deficiência)
Assegura às pessoas com deficiência o direito ao acesso à tecnologia da informação e comunicação, incluindo sistemas e aplicativos. A ABNT NBR 17060:2022 define os requisitos de acessibilidade para produtos e serviços de TI no Brasil. Como técnico, você tem responsabilidade legal e ética de garantir que os usuários tenham acesso igualitário.

🔊 Parte 2 — Ferramentas de Audição
Legendas ao Vivo (Live Captions) — Windows 11 NOVO
1

Ativar Legendas ao Vivo

Disponível no Windows 11 22H2 ou superior. Transcreve qualquer áudio do sistema em texto em tempo real — reuniões, vídeos, podcasts.

Ativar: Win + Ctrl + L — ou Configurações → Acessibilidade → Legendas ao Vivo.

🎤 Legendas ao Vivo — Transcrevendo...

TRANSCREVENDO AO VIVO
2

Alertas Sonoros como Visuais

Para usuários surdos, converta alertas sonoros em piscadas de tela: Configurações → Acessibilidade → Áudio → ative "Usar alertas visuais para avisos de áudio".

✅
Mono Áudio: Ative em Configurações → Acessibilidade → Áudio → "Ativar áudio mono". Essencial para usuários com surdez em um ouvido — garante que todo áudio stereo seja misturado corretamente.
⌨️ Parte 3 — Ferramentas de Mobilidade
Teclado Virtual e Teclas Especiais PRÁTICA
1

Teclado Virtual (osk.exe)

Teclado exibido na tela, operável com mouse, toque ou eye-tracking. Essencial para quem não consegue usar teclado físico por paralisia, tremor severo ou amputação.

Como abrir
# Opção 1: via Executar
Win+R> osk

# Opção 2: via busca
Iniciar → buscar "Teclado Virtual"

# Opção 3: sempre disponível na tela de login
Tela de Login → ícone de Acessibilidade (canto inferior direito)
2

Teclas de Aderência (Sticky Keys)

Permite pressionar combinações de teclas (Ctrl+Alt+Del, Ctrl+C) uma tecla por vez, em sequência. Fundamental para quem usa apenas uma mão ou tem dificuldade de pressionar múltiplas teclas ao mesmo tempo.

⚙️ Acessibilidade → Teclado

Teclas de alternânciaSinal sonoro ao pressionar Caps/Num/Scroll Lock

🎯 Parte 4 — Caso Prático: Configurando para Baixa Visão

Cenário: O Sr. José (68 anos, visão reduzida severa) vai usar o computador do trabalho. Você é o técnico responsável. Faça a configuração completa seguindo este protocolo.

1

Etapa 1 — Resolução e Escala

Configurações → Sistema → Vídeo → Escala → aumente para 150% ou 175%. Isso aumenta todos os elementos da interface proporcionalmente.

2

Etapa 2 — Tamanho do Texto

Configurações → Acessibilidade → Tamanho do texto → ajuste para 125–150%. Combine com o ajuste de escala para resultado melhor.

3

Etapa 3 — Lupa sempre ativa

Configurações → Acessibilidade → Lupa → ative "Iniciar a Lupa após entrar". Configure no modo Tela Cheia com zoom de 150–200%.

4

Etapa 4 — Ponteiro do mouse maior e mais visível

Configurações → Acessibilidade → Ponteiro → tamanho no máximo (15/15), cor invertida (se inverte automaticamente sobre textos/fundos) ou branca com bordas pretas.

5

Etapa 5 — Alto Contraste (se necessário)

Se o usuário tiver sensibilidade à luz ou dificuldade de contraste mesmo com zoom: Alt+Shift+PrtSc ativa/desativa o alto contraste imediatamente.

6

Etapa 6 — Narrador de backup

Configure o Narrador para iniciar automaticamente (Configurações → Acessibilidade → Narrador → Usar o Narrador). Para o Sr. José, isso serve como recurso adicional quando o zoom não for suficiente para ler algum conteúdo.

✅
Boas práticas: Documente todas as configurações feitas em um arquivo de texto simples e salve na Área de Trabalho do usuário. Assim, você ou outro técnico pode reverter ou reconfigurar facilmente.
PowerShell — Verificar configurações de acessibilidade via registro
# Verificar se alto contraste está ativo
PS> Get-ItemProperty "HKCU:\Control Panel\Accessibility\HighContrast" -Name Flags

# Verificar tamanho do cursor
PS> Get-ItemProperty "HKCU:\Control Panel\Cursors" -Name CursorBaseSize

# Verificar escala de exibição atual
PS> Get-ItemProperty "HKCU:\Control Panel\Desktop\WindowMetrics" -Name AppliedDPI
