🔵 Configurando o Windows Update

🔬 Laboratório ⏱ 30 min

📋 Enunciado

Analise e configure as opções do Windows Update para um ambiente de uso corporativo, documentando as melhores práticas.

📊 Rubrica de Avaliação

✅ Resolução Passo a Passo

  1. ▸ Acesse: Configurações → Windows Update
  2. ▸ Verifique se há atualizações pendentes — documente quais são
  3. ▸ Explore as Opções avançadas: observe configurações de entrega de atualização
  4. ▸ Configure: Horário ativo (quando o Windows NÃO deve reiniciar automaticamente)
  5. ▸ Defina horário ativo: 07:00 às 19:00 (horário comercial)
  6. ▸ Ative a opção de receber outras atualizações da Microsoft (Office, etc.)
  7. ▸ Via PowerShell: Install-Module PSWindowsUpdate -Force (se disponível)
  8. ▸ Pesquise: o que é WSUS e como ele funciona em empresas?
  9. ▸ Escreva: qual seria a política de atualização ideal para uma empresa de 50 PCs?
  10. ▸ Salve: 'sem17_ex1_SeuNome.docx'

🔷 Explorando o Editor de Registro com Segurança

🔬 Laboratório ⏱ 35 min

📋 Enunciado

Explore o Editor de Registro do Windows de forma segura, fazendo backup antes e aprendendo a estrutura do registro.

📊 Rubrica de Avaliação
Critério Insuficiente (0–5) Básico (6–7) Proficiente (8–9) Excelente (10)
Funcionamento Não funciona Funciona parcialmente Funciona corretamente Funciona perfeitamente e supera
Estrutura Técnica Estrutura inadequada Estrutura básica funcional Boa estrutura técnica Estrutura exemplar e profissional
Tratamento de Erros Sem tratamento de erros Tratamento mínimo presente Erros bem tratados Tratamento robusto e completo
Eficiência Ineficiente e redundante Pouco eficiente Eficiente Altamente eficiente e otimizado
Documentação Sem comentários ou README Documentação básica Bem documentado Documentação completa e exemplar
Boas Práticas Sem boas práticas Algumas boas práticas Boas práticas aplicadas Segue padrões profissionais

✅ Resolução Passo a Passo

  1. ▸ AVISO: siga as instruções COM CUIDADO — o registro é crítico para o sistema
  2. ▸ Abra: Win+R → regedit
  3. ▸ PRIMEIRO: faça backup completo → Arquivo → Exportar → salve como 'backup_registro.reg'
  4. ▸ Explore a estrutura: expanda HKEY_LOCAL_MACHINE → SOFTWARE → Microsoft → Windows
  5. ▸ Anote 3 chaves interessantes que você encontrar
  6. ▸ Acesse: HKEY_CURRENT_USER → Software → Microsoft → Windows → CurrentVersion → Run
  7. ▸ Esta chave mostra programas que iniciam com o Windows para o usuário atual
  8. ▸ Observe os valores e seus tipos (REG_SZ, REG_DWORD, etc.)
  9. ▸ Crie uma entrada inócua: clique direito na área vazia → Novo → Valor de String → nome: 'Teste' → valor: 'Exercicio'
  10. ▸ Exporte apenas esta chave → depois delete a entrada Teste → reimporte para restaurar
  11. ▸ Salve: 'sem17_ex2_SeuNome.docx' documentando cada etapa

💡 Dica Profissional: Sempre documente o que você fez durante o laboratório. Um técnico sem registros não consegue reproduzir soluções nem comprovar seu trabalho.

☑️ Checklist de Entrega:

AVISO: siga as instruções COM CUIDADO — o registro é crítico para o sistema
Abra: Win+R → regedit
PRIMEIRO: faça backup completo → Arquivo → Exportar → salve como 'backup_registro.reg'

🟢 Políticas de Segurança e Windows Defender

🔬 Laboratório ⏱ 25 min

📋 Enunciado

Configure políticas de segurança locais e verifique o status completo da proteção do Windows Defender.

📊 Rubrica de Avaliação
Critério Insuficiente (0–5) Básico (6–7) Proficiente (8–9) Excelente (10)
Diagnóstico Não identificou o problema Diagnóstico superficial Bom diagnóstico Diagnóstico preciso e completo
Raciocínio Técnico Sem raciocínio lógico Raciocínio básico Bom raciocínio técnico Raciocínio exemplar e sistemático
Solução Aplicada Solução incorreta ou ausente Solução parcial Solução adequada Solução ótima e elegante
Documentação do Processo Sem registro do processo Registro mínimo Processo bem documentado Documentação técnica completa
Eficácia Problema não resolvido Parcialmente resolvido Resolvido satisfatoriamente Resolvido com excelência
Comunicação Incapaz de explicar Explicação básica Explicação clara Comunicação técnica exemplar

✅ Resolução Passo a Passo

  1. ▸ Abra: Win+R → secpol.msc (Política de Segurança Local)
  2. ▸ Navegue: Políticas de Conta → Política de Senha
  3. ▸ Configure: Comprimento mínimo da senha: 8 caracteres
  4. ▸ Configure: A senha deve satisfazer requisitos de complexidade: Ativado
  5. ▸ Configure: Duração máxima da senha: 90 dias
  6. ▸ Navegue: Política de Bloqueio de Conta
  7. ▸ Configure: Limite de bloqueio: 5 tentativas inválidas
  8. ▸ Configure: Duração do bloqueio: 30 minutos
  9. ▸ Abra: Segurança do Windows (Win+S → Segurança do Windows)
  10. ▸ Via PowerShell: Get-MpComputerStatus | Select-Object *Status*
  11. ▸ Documente o status completo do Defender. Salve: 'sem17_ex3_SeuNome.docx'

💡 Dica Profissional: Sempre documente o que você fez durante o laboratório. Um técnico sem registros não consegue reproduzir soluções nem comprovar seu trabalho.

Abra: Win+R → secpol.msc (Política de Segurança Local)
Navegue: Políticas de Conta → Política de Senha
Configure: Comprimento mínimo da senha: 8 caracteres
Configure: A senha deve satisfazer requisitos de complexidade: Ativado
