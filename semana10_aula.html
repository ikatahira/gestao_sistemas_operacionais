📄 Scripts .ps1 — Do Terminal ao Arquivo +20 XP ▾
Scripts PowerShell têm extensão .ps1. Qualquer editor de texto funciona — use o VSCode ou o ISE embutido no Windows.
Por segurança, o Windows bloqueia execução de scripts por padrão. Libere com Set-ExecutionPolicy RemoteSigned (uma vez, como admin).
Para executar: .\meu_script.ps1 — o .\ indica "nesta pasta". Sem ele, o PowerShell não encontra o arquivo.
PASSO 1 Liberar execução de scripts (executar como Administrador)
PS C:\> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
Confirmação — responda Y e Enter
Execution policy change
The execution policy helps protect you from scripts that you do not trust.
Do you want to change the execution policy?
[Y] Yes [N] No [S] Suspend [?] Help (default is "N"): Y

✓ Política alterada. Agora você pode rodar scripts .ps1!
PASSO 2 Criar e executar seu primeiro script
# Crie o arquivo hello.ps1 com este conteúdo:
Write-Host "Olá, $env:USERNAME! Hoje é $(Get-Date -Format 'dd/MM/yyyy')." -ForegroundColor Cyan
Write-Host "Computador: $env:COMPUTERNAME" -ForegroundColor Green

# Agora execute:
PS C:\Scripts> .\hello.ps1
Saída colorida no terminal
Olá, aluno.gso! Hoje é 15/05/2026.
Computador: DESKTOP-LAB01
💡
Write-Host vs Write-Output: Write-Host exibe na tela (cor, formatação). Write-Output envia para o pipeline — útil dentro de funções que outros cmdlets vão consumir.
🔀 If/Else · For · ForEach — Tomando Decisões +20 XP ▾
if/elseif/else — toma decisões. Operadores: -gt maior · -lt menor · -eq igual · -ne diferente.
foreach — percorre cada item de uma lista ou resultado de cmdlet.
for — loop numérico clássico. while — repete enquanto a condição for verdadeira.
EXEMPLO If/Else — alerta de disco cheio
$livreGB = (Get-PSDrive C).Free / 1GB

if ($livreGB -lt 10) {
  Write-Host "🔴 CRÍTICO: apenas $([math]::Round($livreGB,1)) GB livre!" -ForegroundColor Red
} elseif ($livreGB -lt 30) {
  Write-Host "🟡 AVISO: $([math]::Round($livreGB,1)) GB livre" -ForegroundColor Yellow
} else {
  Write-Host "🟢 OK: $([math]::Round($livreGB,1)) GB livre" -ForegroundColor Green
}
Saída — depende do disco do seu PC
🟢 OK: 127.4 GB livre

# Se o disco estivesse quase cheio, apareceria:
🔴 CRÍTICO: apenas 4.2 GB livre!
EXEMPLO ForEach — verificar lista de serviços críticos
$servicos = @('Spooler', 'WinRM', 'Dnscache', 'wuauserv')

foreach ($svc in $servicos) {
  $status = (Get-Service $svc).Status
  if ($status -eq 'Running') {
    Write-Host "✓ $svc — Running" -ForegroundColor Green
  } else {
    Write-Host "✗ $svc — $status ← ALERTA!" -ForegroundColor Red
  }
}
Saída — status de cada serviço em tempo real
✓ Spooler — Running
✓ WinRM — Running
✓ Dnscache — Running
✗ wuauserv — Stopped ← ALERTA!
EXEMPLO For — loop numérico clássico
for ($i = 1; $i -le 5; $i++) {

}

🛡️ Tratamento de Erros — Try / Catch / Finally +20 XP ▾
Sempre use try/catch quando o script pode falhar: arquivo inexistente, serviço que não responde, permissão negada.
$_ dentro do catch contém a mensagem de erro. -ErrorAction Stop força a exceção para ser capturada.
finally sempre executa — seja com sucesso ou com erro. Ideal para limpeza e log de encerramento.
EXEMPLO Try/Catch — lendo arquivo que pode não existir
try {
  $conteudo = Get-Content 'C:\log.txt' -ErrorAction Stop
  Write-Host "✓ Arquivo lido com sucesso!" -ForegroundColor Green
  Write-Host "Linhas: $($conteudo.Count)"
} catch {
  Write-Host "✗ Erro: $_" -ForegroundColor Red
  $_ | Out-File 'C:\erros.log' -Append
} finally {
  Write-Host "Execução finalizada." -ForegroundColor Cyan
}
Cenário A — arquivo existe
✓ Arquivo lido com sucesso!
Linhas: 142
Execução finalizada.

Cenário B — arquivo não existe
✗ Erro: Cannot find path 'C:\log.txt' because it does not exist.
Execução finalizada.
(erro registrado em C:\erros.log)
EXEMPLO Script robusto — verificar e reiniciar serviço com segurança
$nomeServico = 'Spooler'

try {
  $svc = Get-Service -Name $nomeServico -ErrorAction Stop
  if ($svc.Status -ne 'Running') {
    Start-Service $nomeServico
    Write-Host "✓ $nomeServico iniciado!" -ForegroundColor Green
  } else {
    Write-Host "✓ $nomeServico já está rodando." -ForegroundColor Green
  }
} catch {
  Write-Host "✗ Falha: $_" -ForegroundColor Red
}
Saída — serviço já rodando
✓ Spooler já está rodando.
⚠️
Importante: sem -ErrorAction Stop, erros de cmdlet não são capturados pelo catch! Sempre adicione quando quiser tratar falhas de cmdlets.
🔧 Funções Reutilizáveis — Organize seu Código +20 XP ▾
Funções encapsulam código repetido. Use param() para parâmetros e return para devolver valores.
Convenção: siga o padrão Verbo-Substantivo: Get-InfoPC, Set-Config, New-Backup.
Use Write-Verbose em vez de Write-Host dentro de funções — as mensagens só aparecem com -Verbose.
EXEMPLO Função — verificar status de serviço
function Get-StatusServico {
  param(
    [string]$Nome,
    [switch]$Verbose
  )
  $svc = Get-Service -Name $Nome -ErrorAction SilentlyContinue
  if ($Verbose) { Write-Host "Consultando $Nome..." }
  return $svc.Status
}

# Chamando a função:
Get-StatusServico -Nome "Spooler"
Get-StatusServico -Nome "wuauserv" -Verbose
Saída das duas chamadas
Running

Consultando wuauserv...
Stopped
EXEMPLO Função — inventário do PC em uma chamada
function Get-InventarioPC {
  $os = Get-CimInstance Win32_OperatingSystem
  $ramGB = [math]::Round($os.TotalVisibleMemorySize / 1MB, 1)
  $livreGB = [math]::Round((Get-PSDrive C).Free / 1GB, 1)

  Write-Host "=== INVENTÁRIO DO PC ===" -ForegroundColor Cyan
  Write-Host "PC : $env:COMPUTERNAME"
  Write-Host "OS : $($os.Caption)"
  Write-Host "RAM : $ramGB GB"
  Write-Host "Disco: $livreGB GB livres"
}

Get-InventarioPC
Saída — relatório instantâneo do computador
=== INVENTÁRIO DO PC ===
PC : DESKTOP-LAB01
OS : Microsoft Windows 11 Pro
RAM : 16.0 GB
Disco: 127.4 GB livres
