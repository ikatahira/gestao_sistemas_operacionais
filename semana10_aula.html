📝 Estrutura de um Script PowerShell

Um script PowerShell é um arquivo de texto com extensão .ps1. Boas práticas: comece com comentários explicativos (#), declare variáveis no topo, organize em funções, use nomes descritivos. Para executar: clique direito → Executar com PowerShell, ou no PowerShell: .\meu_script.ps1

🔀 Estruturas de Controle

If/Else: if ($x -gt 10) { 'maior' } else { 'menor ou igual' }. Operadores: -eq (igual), -ne (diferente), -gt (maior), -lt (menor), -like (padrão com *). ForEach: foreach ($item in $lista) { ... }. For: for ($i=0; $i -lt 10; $i++) { ... }. While: while ($condicao) { ... }.

🛡️ Tratamento de Erros com Try/Catch

Sempre que o script pode falhar (acessar arquivo que não existe, serviço que não responde), use Try/Catch: try { Get-Content 'arquivo.txt' } catch { Write-Error 'Arquivo não encontrado: $_' }. Isso evita que o script pare abruptamente e permite tratar o erro de forma elegante.

🔧 Funções Reutilizáveis

Funções encapsulam código que você usa várias vezes: function Get-InfoPC { param($computador) return Get-ComputerInfo -ComputerName $computador }. Depois chame: Get-InfoPC 'PC-01'. Funções com parâmetros tornam seus scripts muito mais flexíveis e reutilizáveis.
