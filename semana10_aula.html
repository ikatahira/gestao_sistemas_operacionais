📝 Estrutura de um Script PowerShell +20 XP ▾
Scripts PowerShell são arquivos de texto com extensão .ps1. Para executar: .\meu_script.ps1 no terminal.
Boas práticas: comece com comentários explicativos usando #, declare variáveis no topo, organize em funções com nomes descritivos.
Clique direito no arquivo → Executar com PowerShell; ou dentro do terminal: Set-ExecutionPolicy RemoteSigned para permitir execução.
# Cabeçalho — sempre inclua! # Autor: Seu Nome | Data: 2026 | Versão: 1.0 # Descrição: Script de exemplo com boas práticas param($nome = "Aluno") # parâmetro com padrão $data = Get-Date -Format 'dd/MM/yyyy' Write-Host "Olá, $nome! Hoje é $data" -ForegroundColor Cyan
🔀 Estruturas de Controle +20 XP ▾
Operadores de comparação: -eq igual, -ne diferente, -gt maior, -lt menor, -like padrão com wildcard *.
foreach itera sobre cada item de uma coleção. for usa contador. while repete enquanto condição for verdadeira.
# If / Else $espaco = (Get-PSDrive C).Free / 1GB if ($espaco -lt 5) { Write-Warning "Pouco espaço em disco!" } else { Write-Host "Disco OK: $([math]::Round($espaco,1)) GB livres" } # ForEach — iterar serviços $servicos = @('Spooler','wuauserv','BITS') foreach ($svc in $servicos) { $status = (Get-Service -Name $svc).Status Write-Host "$svc → $status" }
💡 Dica: No PowerShell, strings entre aspas duplas "$variavel" fazem interpolação automática. Aspas simples 'literal' não interpolam.
🛡️ Tratamento de Erros com Try / Catch +20 XP ▾
Sempre use try/catch quando o script pode falhar: arquivo inexistente, serviço que não responde, permissão negada.
$_ dentro do catch contém a mensagem de erro. -ErrorAction Stop força exceção para ser capturada.
try { $conteudo = Get-Content 'C:\log.txt' -ErrorAction Stop Write-Host "Arquivo lido com sucesso!" -ForegroundColor Green } catch { Write-Error "Falha ao ler arquivo: $_" # Log do erro: $_ | Out-File 'C:\erros.log' -Append } finally { Write-Host "Execução finalizada." # sempre roda }
🔧 Funções Reutilizáveis +20 XP ▾
Funções encapsulam código repetido. Use param() para parâmetros e return para devolver valores.
Convenção: siga o padrão Verbo-Substantivo: Get-InfoPC, Set-Config, New-Backup.
function Get-StatusServico { param( [string]$Nome, [switch]$Verbose ) $svc = Get-Service -Name $Nome -ErrorAction SilentlyContinue if ($Verbose) { Write-Host "Consultando $Nome..." } return $svc.Status } # Chamadas: Get-StatusServico -Nome "Spooler" Get-StatusServico -Nome "wuauserv" -Verbose
⚡ Pro tip: Use Write-Verbose em vez de Write-Host dentro de funções — as mensagens só aparecem com -Verbose, deixando o script limpo por padrão.
