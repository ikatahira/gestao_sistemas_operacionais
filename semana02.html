Arquitetura Interna do Windows

O SO é organizado em camadas, como as camadas de uma cebola. As camadas mais internas têm mais poder — e mais responsabilidade. Isso garante segurança: um programa que trava não derruba o sistema todo.

🔧 Hardware — CPU, RAM, Disco, Placa Mãe
O Kernel tem acesso total ao hardware — controla diretamente o processador, a memória e os dispositivos. É o componente mais crítico. Se o Kernel travar, o sistema inteiro trava (famosa "tela azul da morte"). Por isso, apenas componentes do próprio SO rodam nesse modo.
Todo programa que você instala (Word, Chrome, jogos) roda no User Mode, com acesso restrito. Isso é segurança: se o Chrome travar, o Windows continua funcionando porque o Chrome não tem acesso direto ao hardware. Ele precisa "pedir" ao Kernel para fazer coisas críticas.
A Tela Azul da Morte (BSOD) acontece quando há um erro crítico no Kernel Mode — o sistema não consegue continuar. Pode ser causada por drivers com bug, hardware com defeito ou corrupção do sistema. Como técnico, você vai aprender a diagnosticar e resolver BSODs!

Um processo é um programa em execução. Quando você abre o Word, o SO cria um processo "WINWORD.EXE" com um PID (Process ID — número único), uso de RAM, CPU e prioridade. Um processo pode estar em 3 estados — clique em cada um:

Usando a CPU agora
⇄
🟡
Pronto
Aguardando a vez
→
🔵
Bloqueado

Executando: o processo está usando o processador neste momento. Em um sistema com 1 núcleo, apenas 1 processo pode estar executando por vez. O escalonador decide por quanto tempo cada processo fica nesse estado.
Pronto: o processo está pronto para rodar, mas esperando o processador ficar disponível. Quando o escalonador decidir, ele passa para "Executando". A maioria dos processos fica nesse estado a maior parte do tempo.
Bloqueado / Aguardando: o processo está esperando algo externo acontecer — resposta da rede, leitura do disco, input do usuário. Enquanto espera, não consome CPU. Quando o evento ocorre, volta para "Pronto".

💡 Abra o Gerenciador de Tarefas (Ctrl + Shift + Esc) → aba "Detalhes" para ver o PID de cada processo em execução.

O SO distribui a RAM entre todos os processos ativos. Cada processo tem sua área de memória isolada — um processo não pode ler a memória de outro. Isso é segurança fundamental.

RAM (Random Access Memory) é a memória de trabalho do computador — muito rápida, mas volátil (perde tudo ao desligar). Quanto mais programas abertos, mais RAM é consumida. O SO gerencia qual processo usa qual área da RAM.
Quando a RAM acaba, o Windows cria o arquivo de paginação (pagefile.sys) no disco rígido/SSD para simular mais memória. É chamado de memória virtual. Funciona, mas é muito mais lento — o disco é ~100x mais lento que a RAM!
A paginação é o mecanismo de mover dados entre RAM e disco conforme necessário. Quando você percebe o computador "travando" ou o disco trabalhando muito sem motivo aparente, provavelmente a paginação está acontecendo. Solução: fechar programas ou adicionar mais RAM.

O Windows 11 existe em várias edições para diferentes usos. Como técnico, você precisa saber qual recomendar:

Windows 11 Home: para uso doméstico e notebooks pessoais. Tem todos os recursos básicos mas não inclui BitLocker, domínio de rede nem Hyper-V. É a versão que vem pré-instalada em notebooks novos para consumidor.
Windows 11 Pro: adiciona recursos corporativos — BitLocker (criptografia de disco), entrada em domínio de rede (Active Directory), Hyper-V (virtualização), Windows Sandbox e Group Policy. Ideal para empresas e profissionais de TI.
Windows 11 Enterprise: para grandes corporações. Inclui tudo do Pro mais recursos de gerenciamento centralizado, segurança avançada (Windows Defender Credential Guard) e implantação em larga escala. Geralmente licenciado por volume.
Windows Server 2022: não é para estações de trabalho — é para servidores e data centers. Gerencia Active Directory, DNS, DHCP, hospeda aplicações e serviços para outros computadores da rede. É diferente do Windows de desktop.
