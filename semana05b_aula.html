📁 Fase 1 — Criar Pastas com PowerShell

Use o terminal para criar toda a estrutura de uma vez, como um profissional

+100 XP
🧠 Por que usar PowerShell para criar pastas?
O PowerShell é o terminal avançado do Windows. Em vez de clicar pasta por pasta no Explorer, você escreve um comando e cria dezenas de pastas em segundos. É mais rápido, repetível e profissional — exatamente o que um técnico de TI faz no dia a dia.
O comando principal é New-Item. Para criar uma pasta, usamos New-Item -ItemType Directory -Path "caminho". O atalho mkdir funciona igualmente bem.

💻 Criando tudo com PowerShell

Passo 1: Abra o PowerShell como Administrador — pressione Win + X e escolha Terminal (Admin) ou PowerShell (Admin).

Windows PowerShell — Criar estrutura completa
# Definir pasta raiz — troque "Aluno" pelo seu usuário
PS> $raiz = "$env:USERPROFILE\Documentos\MeuOrganizador"

# Criar as pastas principais com subpastas de uma vez
PS> $pastas = @(
  "Escola\GSO_I",
  "Escola\Matematica",
  "Escola\Portugues",
  "Escola\Trabalhos",
  "Escola\Curriculo",
  "Pessoal\Fotos",
  "Pessoal\Musicas",
  "Pessoal\Downloads_Organizados",
  "Profissional\Projetos_TI",
  "Profissional\Certificados",
  "Profissional\Scripts"
)

# Loop: cria cada pasta (e as pai automaticamente)
PS> foreach ($p in $pastas) {
  New-Item -ItemType Directory -Path "$raiz\$p" -Force | Out-Null
  Write-Host "✔ Criada: $p" -ForegroundColor Green
}

✔ Criada: Profissional\Scripts
Verificar o que foi criado
# Ver a estrutura completa em árvore
PS> tree "$raiz"

# Contar quantas pastas foram criadas

11

# Abrir a pasta no Explorer
PS> explorer "$raiz"
💡
Dica Pro: O parâmetro -Force evita erros caso a pasta já exista. O | Out-Null esconde a saída verbosa do comando, deixando o terminal mais limpo.

🗜️ Fase 4 — Compactar a Pasta em ZIP

Compressão: agrupe e reduza arquivos para enviar facilmente

+100 XP
📦 O que é um arquivo ZIP?
Um arquivo .zip agrupa múltiplos arquivos e pastas em um único arquivo compactado. Isso facilita o envio por e-mail (1 arquivo em vez de muitos) e reduz o tamanho. O Windows 11 cria e extrai ZIP de forma nativa — sem instalar nada.
🖱️ Método 1 — Explorador de Arquivos (mais fácil)
1

Localizar a pasta

Abra o Explorador de Arquivos (Win+E). Navegue até Documentos\MeuOrganizador e clique uma vez na pasta para selecioná-la (não abrir).

2

Compactar

Clique com o botão direito na pasta selecionada → Compactar em arquivo ZIP. No Windows 11, essa opção aparece diretamente no menu ou dentro de "Mostrar mais opções" → "Enviar para" → "Pasta compactada".

Menu de contexto — Botão direito
📋 Copiar
✂️ Recortar
🗜️ Compactar em arquivo ZIP ◄
🗑️ Excluir
3

Nomear o arquivo ZIP

O Windows vai criar um arquivo chamado MeuOrganizador.zip na mesma pasta. Você pode renomear para algo mais descritivo como MeuOrganizador_2026.zip.

Resultado na pasta Documentos

🗜️

💻 Método 2 — PowerShell (mais rápido)
PowerShell — Compactar com Compress-Archive
# Compactar a pasta em ZIP com PowerShell
PS> $origem = "$env:USERPROFILE\Documentos\MeuOrganizador"
PS> $destino = "$env:USERPROFILE\Documentos\MeuOrganizador_2026.zip"

PS> Compress-Archive -Path $origem -DestinationPath $destino -Force

# Verificar tamanho do arquivo ZIP criado
PS> (Get-Item $destino).length / 1KB
2.34 ← tamanho em KB
📏
Por que o ZIP é pequeno? Pastas vazias comprimem quase 100%. À medida que você adicionar arquivos, o ZIP crescerá, mas sempre menor que o original — especialmente com documentos de texto.

Descompactar — Método PowerShell

PowerShell — Expand-Archive
# Extrair o ZIP para a Área de Trabalho
PS> $zip = "$env:USERPROFILE\Downloads\MeuOrganizador_2026.zip"
PS> $destino = "$env:USERPROFILE\Desktop\MeuOrganizador_Extraido"

PS> Expand-Archive -Path $zip -DestinationPath $destino -Force

# Verificar estrutura extraída
PS> tree $destino

└── MeuOrganizador
    ├── Escola
    ├── Pessoal
    └── Profissional

🎯 E-mail Profissional com Currículo
Enviar um currículo por e-mail parece simples, mas há erros comuns que eliminam candidatos antes mesmo da leitura. Veja o modelo correto e os principais erros a evitar.
1

Preparar o arquivo do currículo

Salve seu currículo em PDF (formato universal — qualquer computador abre igual). Nomeie assim: Curriculo_SeuNome_2026.pdf. Evite nomes genéricos como "curriculo_final_v3_DEFINITIVO.docx" — passa má impressão.

📄
Como salvar em PDF no Word: Arquivo → Salvar Como → Tipo: PDF. No Google Docs: Arquivo → Fazer Download → PDF.
2

Redigir o e-mail de apresentação

O corpo do e-mail deve ser curto, profissional e direto. Veja o modelo abaixo:

Segue meu currículo em anexo para sua apreciação. Fico à disposição para entrevista.

📱 (XX) 9XXXX-XXXX
📧 seuemail@gmail.com
📎 Curriculo_SeuNome_2026.pdf
3

Verificar antes de enviar — Checklist

  • O assunto está claro e profissional? (não vazio!)
  • O destinatário está correto? (confira duas vezes!)
  • O PDF foi anexado? (erro mais comum)
  • O corpo do texto não tem erros de digitação?
  • Seu nome e contato estão no final do e-mail?
  • O arquivo PDF abre corretamente? (teste antes de enviar)
4

Enviar e confirmar nos Itens Enviados

Clique Enviar. Depois acesse Itens Enviados e confirme que o e-mail com o anexo foi entregue corretamente. Pronto — candidatura profissional realizada!

❌

❌

❌
