⚙️ Parte 1 — Configuração do Sistema (msconfig)
O que é o msconfig? CONCEITO

O msconfig é o painel de controle da inicialização do Windows. É a primeira ferramenta que um técnico usa quando o PC está lento para iniciar ou tem problemas causados por programas de terceiros.

AbaO que fazQuando usar
GeralEscolhe o tipo de inicialização (Normal, Diagnóstico, Seletiva)Para isolar problemas
InicializaçãoConfigura modos de boot (seguro, etc.)Para entrar no Modo Seguro sem F8
ServiçosAtiva/desativa serviços na inicializaçãoPara diagnóstico de conflitos
FerramentasAtalhos para ferramentas do WindowsAcesso rápido a diagnósticos
Passo a passo: Usando o msconfig PRÁTICA
1

Abrir o msconfig

Pressione Win + R → digite msconfig → Enter. Ou busque "Configuração do Sistema" no menu Iniciar.

💡
Diagnóstico rápido: Use "Inicialização de diagnóstico" para ver se o problema desaparece sem serviços de terceiros. Se desaparecer, algum serviço instalado é o culpado.
2

Aba Serviços: Isolando conflitos

Vá para a aba Serviços. Marque "Ocultar todos os serviços Microsoft" — assim você vê apenas serviços de terceiros (aplicativos instalados). Desative todos e reinicie. Se o problema sumir, reative pela metade, reinicie, e vá identificando o culpado.

3

Aba Inicialização: Entrar no Modo Seguro sem F8

Na aba Inicialização, marque "Inicialização segura" e escolha o tipo. Ao clicar em OK e reiniciar, o Windows entra automaticamente no Modo Seguro — sem precisar pressionar F8 (que muitas vezes não funciona em PCs modernos com boot rápido).

⚠️
Lembre-se: Após o diagnóstico, volte ao msconfig e desmarque a inicialização segura. Caso contrário, o PC ficará preso no Modo Seguro toda vez que reiniciar!

Entrar no Modo Seguro — Método moderno PRÁTICA
1

Via Configurações (PC ligado normalmente)

Vá em Configurações → Sistema → Recuperação → Inicialização Avançada → Reiniciar Agora. O Windows reiniciará mostrando um menu de opções.

2

No menu de recuperação, navegue:

Solução de Problemas → Opções Avançadas → Configurações de Inicialização → Reiniciar

Após reiniciar, pressione 4 para Modo Seguro, 5 para Modo Seguro com Rede, ou 6 para Modo Seguro com Prompt.

3

Via PowerShell (forma mais rápida para técnicos)

PowerShell (Administrador)
# Reiniciar direto no menu de recuperação
PS> shutdown /r /o /t 0

# Configurar para iniciar em modo seguro no próximo boot
PS> bcdedit /set {current} safeboot minimal
Operação concluída com êxito.

# Para voltar ao normal após o diagnóstico:
PS> bcdedit /deletevalue {current} safeboot
🔧 Parte 3 — Windows Recovery Environment (WinRE)
O que é o WinRE? CONCEITO

O WinRE é como um "Windows de emergência" — uma versão mínima que fica guardada em uma partição separada. Ele inicia automaticamente quando o Windows principal falha três vezes seguidas, ou você pode acessá-lo manualmente.

Ferramentas do WinRE: Opções Avançadas PRÁTICA
1

Reparo de Inicialização (Startup Repair)

Solução de Problemas → Opções Avançadas → Reparo de Inicialização. O Windows tenta automaticamente corrigir arquivos de boot danificados. Use como primeiro recurso quando o Windows não inicia.

2

Restauração do Sistema

Volta o Windows a um "ponto de restauração" anterior — antes de uma atualização ou instalação problemática. Não apaga arquivos pessoais, apenas desfaz mudanças no sistema.

💡
Boas práticas: Sempre crie um ponto de restauração antes de instalar drivers, programas desconhecidos, ou editar o Registro. Use: rstrui.exe ou Painel de Controle → Sistema → Proteção do Sistema.
3

Prompt de Comando no WinRE

A ferramenta mais poderosa do WinRE. Com ela você executa comandos avançados de recuperação:

Prompt de Comando — WinRE
# Reparar o registro mestre de boot (MBR)
X:\> bootrec /fixmbr
A operação foi concluída com êxito.

# Reparar o setor de boot
X:\> bootrec /fixboot

# Reconstruir o Boot Configuration Data
X:\> bootrec /rebuildbcd

# Verificar e reparar arquivos de sistema
X:\> sfc /scannow

# Reparar imagem do Windows
X:\> DISM /Online /Cleanup-Image /RestoreHealth
🚨 Parte 4 — Diagnóstico de Problemas Comuns de Boot
Tela Azul (BSOD) — Como interpretar VISUAL
:(
Seu PC encontrou um problema e precisa ser reiniciado. Estamos apenas coletando algumas informações de erro e depois reiniciaremos para você.
0% concluído
Se quiser saber mais, pesquise online este erro mais tarde:
CRITICAL_PROCESS_DIED
Para mais informações sobre esse problema e possíveis correções, acesse https://www.windows.com/stopcode
📸
Primeiro passo quando vir um BSOD: Fotografe a tela com o celular para ter o código de erro. Depois pesquise o código (ex: CRITICAL_PROCESS_DIED, IRQL_NOT_LESS_OR_EQUAL) no site da Microsoft ou Google.
Guia de Diagnóstico: Problemas × Soluções REFERÊNCIA
🔴
"BOOTMGR is missing" ou "No bootable device"

O gerenciador de boot não foi encontrado — arquivo corrompido ou disco não está sendo detectado.

WinRE → Prompt → bootrec /fixmbr → bootrec /fixboot → bootrec /rebuildbcd
🟡
Loop de reinicialização infinito

O Windows começa a carregar, trava, reinicia, repete. Geralmente causado por uma atualização com falha.

WinRE → Opções Avançadas → Reparo de Inicialização — ou — Restauração do Sistema
🔴
BSOD repetido com código de erro

Anote o código → pesquise → se for driver: Modo Seguro → desinstalar driver. Se for hardware: rodar diagnóstico de memória e disco.

Modo Seguro → Gerenciador de Dispositivos → Reverter/Desinstalar driver
🟡
Windows muito lento no boot (mais de 2 minutos)

Muitos programas iniciando junto com o Windows. Sem necessidade de WinRE — o Windows ainda funciona.

msconfig → Serviços (desativar terceiros) + Gerenciador de Tarefas → Inicialização
🟢
Arquivo de sistema corrompido (erros aleatórios)

O Windows funciona mas com erros, travamentos, aplicativos que não abrem. O SFC verifica e repara arquivos corrompidos.

sfc /scannow (como Administrador) → DISM /Online /Cleanup-Image /RestoreHealth
PowerShell — Sequência completa de diagnóstico
# 1. Verificar arquivos do sistema
PS> sfc /scannow

# 2. Se sfc encontrar erros que não conseguiu reparar, use DISM:
PS> DISM /Online /Cleanup-Image /CheckHealth
PS> DISM /Online /Cleanup-Image /ScanHealth
PS> DISM /Online /Cleanup-Image /RestoreHealth

# 3. Verificar erros no disco (chkdsk)
PS> chkdsk C: /f /r
O chkdsk não pode ser executado agora. Agendar para próximo boot? [S] S

# 4. Verificar log de erros do sistema
PS> Get-EventLog -LogName System -EntryType Error -Newest 20
🔬 Atividades Práticas

Acesse o Guia de Exercícios para rubricas e resoluções detalhadas.

1
Configurando a Inicialização com msconfig
⏱ 30 min🔬 Laboratóriomsconfig
Use o msconfig para analisar e otimizar a configuração de inicialização, identificando serviços e programas desnecessários.
  • Abra o msconfig e anote quantos serviços de terceiros estão ativos
  • Desative todos os serviços de terceiros e reinicie
  • Meça o tempo de boot antes e depois da desativação
  • Reative um por um até identificar quais são necessários
  • Documente o resultado em relatório (use Export-Csv no PowerShell)
2
Explorando o Modo de Segurança
⏱ 35 min🔬 LaboratórioSafe Mode
Configure e entre no Modo de Segurança do Windows para explorar as diferenças em relação ao modo normal.
  • Configure o Modo Seguro via msconfig (aba Inicialização)
  • Reinicie e observe: quais programas NÃO abrem no Modo Seguro?
  • Verifique a resolução de tela e a aparência do Desktop
  • Use o PowerShell: Get-Service | Where Status -eq Running | Measure-Object para contar serviços ativos e compare com o modo normal
  • Volte ao modo normal desmarcando a opção no msconfig
3
Simulação de Diagnóstico de Problemas de Boot
⏱ 25 min📝 Pesquisasfc / DISM
Execute a sequência de diagnóstico e documente os procedimentos para os problemas de boot mais comuns.
  • Execute sfc /scannow e documente o resultado
  • Execute DISM /Online /Cleanup-Image /CheckHealth
  • Execute Get-EventLog -LogName System -EntryType Error -Newest 10 e interprete os erros encontrados
  • Crie um documento com o "Protocolo de Diagnóstico de Boot" para usar como referência
