📂 Gerenciamento de Arquivos com PowerShell

PowerShell é muito poderoso para gerenciar arquivos. Os cmdlets principais: New-Item (cria arquivo ou pasta), Copy-Item (copia), Move-Item (move), Remove-Item (deleta), Rename-Item (renomeia), Get-ChildItem (lista). Você pode aplicar esses comandos em múltiplos arquivos de uma vez, o que seria impossível na interface gráfica sem muito esforço.

🔗 O Pipeline: O Coração do PowerShell

O pipeline (|) conecta a saída de um cmdlet à entrada do próximo. Exemplo: Get-Process | Where-Object {$_.CPU -gt 10} | Sort-Object CPU | Select-Object Name, CPU. Leia: 'Pega os processos → filtra os que usam mais de 10% de CPU → ordena por CPU → mostra só nome e CPU'. Este encadeamento é incrivelmente poderoso.

🔎 Filtragem e Formatação de Saídas

Where-Object filtra: Get-Service | Where-Object {$_.Status -eq 'Running'} (mostra só serviços rodando). Select-Object escolhe colunas: Get-Process | Select-Object Name, CPU, WorkingSet. Format-Table formata em tabela. Format-List formata em lista vertical. Export-Csv exporta para Excel!

📊 Variáveis no PowerShell

Variáveis começam com $: $nome = 'João'; $numero = 42; $lista = Get-Process. Você pode armazenar qualquer coisa numa variável e reutilizar depois. Exemplo: $processos = Get-Process; $processos | Where-Object {$_.CPU -gt 5}. A variável especial $_ representa o objeto atual dentro de pipes e laços.
