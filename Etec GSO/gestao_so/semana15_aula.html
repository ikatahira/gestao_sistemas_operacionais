🔧 Manutenção Preventiva vs. Corretiva

Manutenção preventiva: ações regulares para evitar problemas (desfragmentar, limpar, atualizar). Manutenção corretiva: ações para resolver problemas já ocorridos (reparar, restaurar). Um bom técnico prioriza a prevenção — é muito mais barato e menos estressante do que corrigir depois. A manutenção preventiva regular pode triplicar a vida útil de um computador.

💿 Desfragmentação e Otimização de Disco

HDDs (discos mecânicos) fragmentam: os dados se dispersam pelo disco, deixando-o lento. Desfragmentar reordena esses dados. SSDs não devem ser desfragmentados (danifica o disco) — o Windows faz a otimização adequada (TRIM) automaticamente. Para verificar o tipo de disco: Painel de Controle → Ferramentas Administrativas → Desfragmentar e Otimizar Unidades.

🛡️ Verificador de Arquivos do Sistema (SFC)

O comando sfc /scannow verifica e repara arquivos do sistema corrompidos. Deve ser executado no Prompt de Comando como Administrador. O DISM (Deployment Image Servicing and Management) é uma ferramenta mais poderosa para reparar a imagem do Windows: DISM /Online /Cleanup-Image /RestoreHealth. Use SFC primeiro; se falhar, use DISM e depois SFC novamente.

⏮️ Pontos de Restauração do Sistema

Pontos de restauração são 'fotos' do estado do sistema que permitem voltar a uma configuração anterior se algo der errado. O Windows cria automaticamente antes de atualizações e instalações. Você pode criar manualmente antes de alterações importantes. Acesse: Este Computador → Propriedades → Proteção do Sistema → Criar. Não substitui backup! Apenas salva configurações do sistema, não arquivos pessoais.
