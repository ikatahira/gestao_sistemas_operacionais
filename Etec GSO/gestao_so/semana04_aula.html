🚀 Menu Iniciar do Windows 11

O novo menu Iniciar do Windows 11 é centralizado e simplificado. Contém: Apps fixados (você pode personalizar), Apps recomendados (baseado no uso recente), campo de pesquisa. Clique em 'Todos os apps' para ver a lista completa. Para fixar um app: encontre-o, clique direito → 'Fixar no Início'. Para empresas, o menu Iniciar pode ser configurado via política de grupo.

🖥️ Configuração Multi-Monitor

Conectar múltiplos monitores aumenta muito a produtividade. No Windows: Configurações → Sistema → Tela. Você pode: estender a tela (área de trabalho maior em 2 monitores), duplicar (mesma imagem em ambos — útil para apresentações), mostrar apenas em um dos monitores. Atalho: Win+P abre rapidamente as opções de projeção.

🔔 Central de Ações e Notificações

A Central de Ações (ícone no canto direito da barra) traz: notificações de apps e sistema, controles rápidos (Wi-Fi, Bluetooth, modo avião, brilho, volume). Em ambientes corporativos, gerenciar notificações é importante para manter o foco. Configure: Configurações → Sistema → Notificações.

👤 Contas de Usuário no Windows

O Windows suporta múltiplos tipos de conta: Administrador (controle total do sistema), Usuário Padrão (uso normal, sem instalar programas), Conta Microsoft (sincroniza configurações com a nuvem), Conta Local (sem internet, mais privada). No suporte técnico, é comum criar contas padrão para usuários finais para proteger o sistema.
