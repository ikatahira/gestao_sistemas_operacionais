💻 O que é o PowerShell?

PowerShell é uma linguagem de script e shell de linha de comando desenvolvida pela Microsoft. Diferente do Prompt de Comando (cmd) antigo, o PowerShell é orientado a objetos — ele trabalha com objetos .NET, não apenas com texto. É a ferramenta padrão para automação em ambientes Windows, Azure, e Microsoft 365. Todo administrador Windows precisa saber PowerShell!

🎯 Por que PowerShell importa?

Com PowerShell você pode: renomear 1000 arquivos em segundos, criar 50 usuários no Active Directory de uma vez, verificar o status de serviços em 100 computadores remotamente, automatizar backups, gerar relatórios do sistema. O que levaria horas feito manualmente leva segundos com um script PowerShell.

📝 Estrutura dos Cmdlets: Verbo-Substantivo

Os comandos do PowerShell (chamados cmdlets) seguem um padrão consistente: Verbo-Substantivo. Exemplos: Get-Process (obtém processos), Stop-Service (para serviço), New-Item (cria item), Remove-Item (remove item), Set-Location (define localização/pasta). Get = obter/listar, Set = definir/alterar, New = criar, Remove = remover, Start/Stop = iniciar/parar.

⚙️ Configurando o PowerShell

Abra o PowerShell: Win+X → PowerShell/Terminal do Windows. O PowerShell 5.1 vem com o Windows. O PowerShell 7+ (mais recente, multiplataforma) pode ser instalado separadamente. Política de execução: por padrão, scripts são bloqueados. Para desenvolvimento: Set-ExecutionPolicy RemoteSigned. Para produção: mantenha a política mais restritiva possível.
