🔐 Permissões NTFS

O sistema de arquivos NTFS (padrão do Windows) permite controlar quem pode fazer o quê com cada arquivo ou pasta. Permissões básicas: Leitura (ver o conteúdo), Gravação (modificar), Execução (rodar programas), Controle Total (tudo). Para configurar: clique direito → Propriedades → Segurança → Editar. Em empresas, isso é gerenciado pelo administrador via Active Directory.

📋 Operações Essenciais com Arquivos

Copiar vs. Mover: Copiar (Ctrl+C, Ctrl+V) cria uma segunda cópia — o original permanece. Mover (Ctrl+X, Ctrl+V) transfere o arquivo — o original some do local de origem. Arrastar entre pastas no mesmo disco = Mover. Arrastar entre discos diferentes = Copiar. Para renomear: F2 ou clique lento no nome.

🗑️ Lixeira: Sua Rede de Segurança

Arquivos excluídos do disco local vão para a Lixeira — você pode restaurá-los! Arquivos excluídos de pendrive ou rede são deletados permanentemente (sem passar pela Lixeira). Para excluir definitivamente sem passar pela Lixeira: Shift+Delete. A Lixeira tem tamanho limitado (configurável) e quando cheia, os arquivos mais antigos são deletados permanentemente.

⚡ Operações em Lote

Para selecionar múltiplos arquivos: Ctrl+clique (seleção individual), Shift+clique (seleciona um intervalo), Ctrl+A (seleciona tudo). Com vários arquivos selecionados, você pode: copiar, mover, excluir, ou comprimir todos de uma vez. Muito mais eficiente do que fazer um por um!
