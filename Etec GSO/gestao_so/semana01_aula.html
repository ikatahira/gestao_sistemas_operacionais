📖 1. O que é um Sistema Operacional?

🤔 Pense assim…

Imagine um restaurante. Você (o cliente) quer comer um prato. A cozinha tem todos os ingredientes e equipamentos (hardware). Mas alguém precisa organizar os cozinheiros, controlar os pedidos e garantir que ninguém interfira no trabalho do outro. Esse "gerente da cozinha" é o Sistema Operacional.

💡 Resumindo: o SO é o intermediário entre você e o hardware do computador. Sem ele, você precisaria falar "binário" com o processador!

⚙️ O que o SO faz na prática?

O Sistema Operacional cuida de 4 tarefas principais: gerenciar o processador (CPU), gerenciar a memória (RAM), gerenciar os dispositivos de armazenamento (HD/SSD) e gerenciar os periféricos (teclado, mouse, impressora). Tudo isso acontece automaticamente enquanto você usa o notebook!

💡 No seu notebook: Windows é o SO mais comum. Outros exemplos: macOS (Apple), Linux (servidores e programadores), Android (celulares), iOS (iPhone).

📋 Funções do SO no dia a dia

Interface com o usuário: a tela que você vê, os ícones, as janelas — tudo isso é o SO. Segurança: senhas de login, permissões de arquivos. Multitarefa: abrir o YouTube e o Word ao mesmo tempo. Drivers: faz o SO "conversar" com impressoras, pendrives, etc.

📖 2. Tipos de Sistemas Operacionais

📌 Monotarefa

Executa apenas um programa por vez. Quando você abre um segundo programa, o primeiro é interrompido. Exemplo clássico: MS-DOS (usado antes do Windows). Hoje, raramente usado — ficou no passado. É como um caixa de banco que atende um cliente de cada vez e faz os outros esperarem até terminar.

📌 Multitarefa

Executa vários programas simultaneamente (ou quase — na verdade o processador alterna entre eles muito rapidamente). É o que o Windows, macOS e Linux fazem. Você ouve música, responde e-mail e navega no YouTube ao mesmo tempo — isso é multitarefa!

💡 Dica prática: pressione Ctrl + Shift + Esc para abrir o Gerenciador de Tarefas e ver todos os processos rodando ao mesmo tempo!

📌 Multiusuário

Permite que vários usuários usem o sistema ao mesmo tempo, cada um com seu perfil e permissões. Muito comum em servidores de empresas e universidades. Linux e Windows Server são exemplos. Cada usuário tem sua área isolada.

📌 Multiprocessado

Usa múltiplos processadores (ou núcleos) ao mesmo tempo para processar tarefas mais rapidamente. Seu notebook provavelmente tem um processador com 4, 6 ou 8 núcleos — isso é multiprocessamento! Cada núcleo é como uma "pista" adicional numa estrada.

💡 Para ver quantos núcleos tem seu processador: Win + R → digite msinfo32 → procure "Processador"

Um sistema que executa apenas UM programa por vez é chamado de:

✅ Perfeito! Multitarefa permite vários programas rodando ao mesmo tempo. Windows é multitarefa!
❌ Errou! Isso é Multitarefa — vários programas rodando simultaneamente. É o que o Windows faz!

✅ Correto! Multiusuário = vários usuários acessando o mesmo sistema com perfis independentes.
❌ Não! Vários usuários no mesmo sistema = Multiusuário. Cada um tem seu login e área separada.
4
Seu notebook tem processador com 8 núcleos. Que tipo de SO aproveita todos eles?
✅ Exato! Multiprocessado aproveita múltiplos núcleos/processadores para rodar tarefas em paralelo.
❌ Errou! Multiprocessado = usa múltiplos núcleos/processadores ao mesmo tempo.
📖 3. Evolução do Windows

🕰️ Windows 1.0 a 3.11 (1985–1994)

O Windows começou como uma "casca gráfica" em cima do MS-DOS. Windows 1.0 (1985) era bem simples — apenas janelas básicas. Windows 3.1 (1992) foi o primeiro a ser realmente popular, com ícones e mouse funcionando bem. Ainda dependia do MS-DOS para funcionar.

🕰️ Windows 95 a ME (1995–2000)

Windows 95 foi REVOLUCIONÁRIO: inventou o botão Iniciar, a barra de tarefas e o conceito de plug-and-play. Windows 98 melhorou a compatibilidade com internet. Windows ME (Millennium Edition) tentou ser o "Windows do novo milênio" mas ficou famoso por ser instável.

💡 Curiosidade: o som de inicialização do Windows 95 foi composto por Brian Eno, um músico famoso, contratado pela Microsoft!

🕰️ Windows XP a Vista (2001–2007)

Windows XP (2001) é considerado o melhor Windows até hoje por muitos técnicos — foi estável, popular e durou mais de 12 anos no mercado! Windows Vista (2007) tentou ser mais bonito mas exigia muito hardware e ficou com reputação negativa.

🕰️ Windows 7 a 10 (2009–2015)

Windows 7 "consertou" os erros do Vista e voltou a ser amado. Windows 8 foi polêmico por remover o botão Iniciar. Windows 8.1 corrigiu isso. Windows 10 (2015) trouxe de volta o Iniciar, atualizações automáticas e integração com nuvem. Suporte ao Win 10 encerrou em outubro de 2025.

🕰️ Windows 11 (2021–atual)

Windows 11 redesenhou a interface: botão Iniciar centralizado, novo menu Iniciar, Snap Layouts para organizar janelas, e requisitos de hardware mais altos (precisa de TPM 2.0). É o Windows atual nos notebooks novos. Como técnico, você precisará dominar o Win 11!

💡 Para verificar se seu notebook roda Win 11: Win + R → winver → aparece sua versão atual.

🖥️ Identificando seu Sistema Operacional
⏱ 10 min ⚡ +50 XP 🎯 Iniciante
Vamos descobrir todas as informações sobre o SO instalado no seu notebook. Você vai aprender a usar ferramentas nativas do Windows que todo técnico precisa conhecer!

📋 Passo a Passo

  1. Pressione Win + R para abrir o "Executar"
  2. Digite winver e pressione Enter → veja a versão do Windows
  3. Feche essa janela e aperte Win + R novamente
  4. Digite msinfo32 e pressione Enter → veja informações completas do sistema
  5. Procure: "Versão do SO", "Processador", "Memória RAM instalada"
  6. Anote o que você encontrou (versão, processador, RAM)
