⚙️ Processos vs. Serviços

Processo: um programa em execução iniciado pelo usuário ou pelo sistema. Serviço: um processo especial que roda em segundo plano, geralmente sem interface visual, gerenciado pelo Windows Service Control Manager (SCM). Serviços podem iniciar automaticamente com o Windows, independente de usuário logado — fundamental para servidores e tarefas agendadas.

📊 Gerenciador de Tarefas Avançado

O Gerenciador de Tarefas tem muito mais do que parece: aba Processos mostra CPU, RAM, Disco, Rede e GPU. Aba Desempenho mostra gráficos históricos. Aba Usuários mostra o consumo por conta. Resource Monitor (acessível pelo Gerenciador de Tarefas) é ainda mais detalhado: mostra quais arquivos cada processo acessa, conexões de rede por processo, etc.

🔧 Gerenciando Serviços

Formas de gerenciar serviços: Serviços (services.msc) — interface gráfica completa. PowerShell: Get-Service, Start-Service, Stop-Service, Set-Service. Tipos de inicialização: Automático (inicia com Windows), Automático (Início Atrasado) — inicia após a inicialização para não atrasar o boot, Manual (só inicia quando chamado), Desativado (nunca inicia).

💾 Gerenciamento de Memória Windows

Windows usa memória RAM de forma inteligente: SuperFetch pré-carrega programas usados frequentemente. Memória virtual (arquivo de paginação no disco) complementa a RAM. Memória RAM usada não significa sistema lento — o Windows usa RAM livre para cache. Problema real: quando a RAM física acaba e o Windows fica usando muito o arquivo de paginação (swap).
