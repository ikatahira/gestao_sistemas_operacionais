📁 O Explorador de Arquivos

O Explorador de Arquivos (Win+E) é a ferramenta central para gerenciar arquivos no Windows. O painel esquerdo mostra a árvore de diretórios; o painel direito mostra o conteúdo. No Windows 11, a barra de ferramentas foi redesenhada mas mantém as funções essenciais: Novo, Recortar, Copiar, Colar, Renomear, Excluir, Classificar, Visualizar.

🏷️ Atributos de Arquivos

Todo arquivo tem atributos que controlam seu comportamento: Somente Leitura (não pode ser modificado), Oculto (não aparece na listagem normal), Sistema (arquivos críticos do SO — não mexa!), Arquivo (marcado para backup). Para ver arquivos ocultos: Explorador → Ver → Itens Ocultos. Para ver arquivos de sistema: Explorador → Opções → Ver → desmarque 'Ocultar arquivos protegidos'.

🗂️ Organização Profissional de Pastas

Boas práticas para estrutura de pastas: use nomenclatura consistente (sem acentos, sem espaços quando possível), organize por projeto ou por data, mantenha uma profundidade máxima de 4-5 níveis de subpastas (mais que isso dificulta a navegação), use datas no formato AAAA-MM-DD para facilitar ordenação automática.

🔍 Pesquisa Avançada no Windows

O Windows oferece pesquisa poderosa: use a barra de pesquisa do Explorador para buscar dentro de uma pasta. Filtros úteis: tipo:*.pdf (busca PDFs), data:>2024 (arquivos de 2024), tamanho:>10MB. A busca indexada (configurável via Opções de indexação) é mais rápida mas não cobre todos os locais do disco.
