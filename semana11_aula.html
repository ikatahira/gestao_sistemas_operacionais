🌐 O que é PowerShell Remoting? +20 XP ▾
O PowerShell Remoting permite executar comandos em computadores remotos como se estivesse localmente. Usa o protocolo WSMan (WS-Management) via HTTP/HTTPS.
Para administradores de rede é essencial: gerencia dezenas de servidores sem Remote Desktop, economiza tempo e padroniza tarefas.
Em domínios Windows pode ser habilitado via Política de Grupo (GPO) para todos os computadores de uma só vez.
💡 Analogia: é como ter um controle remoto universal para todos os computadores da rede — você digita aqui, executa lá.
⚙️ Habilitando o WinRM +20 XP ▾
Enable-PSRemoting -Force configura o serviço WinRM, cria regras de firewall e define permissões.
Verifique se está ativo: Get-Service WinRM → deve mostrar Running.
# 1. Habilitar o serviço WinRM Enable-PSRemoting -Force # 2. Verificar status Get-Service WinRM # 3. Testar conectividade local Test-WSMan localhost # 4. Adicionar host confiável (se fora de domínio) Set-Item WSMan:\localhost\Client\TrustedHosts -Value "192.168.1.*"
💻 Sessões Remotas na Prática +20 XP ▾
Invoke-Command: executa bloco de script em 1 ou mais PCs remotos — ideal para tarefas em lote.
Enter-PSSession: abre sessão interativa (como SSH). Exit-PSSession para sair. O prompt muda para [PC-01]:.
New-PSSession + Remove-PSSession: sessão persistente — reutilize sem autenticar novamente.
# Executar comando remoto (pontual) Invoke-Command -ComputerName 'PC-01' -ScriptBlock { Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 } # Sessão interativa Enter-PSSession -ComputerName localhost # [localhost]: PS C:\> ← você está "dentro" do PC remoto Exit-PSSession # Sessão persistente (mais eficiente) $s = New-PSSession -ComputerName 'PC-01' Invoke-Command -Session $s -ScriptBlock { $env:COMPUTERNAME } Remove-PSSession $s # sempre feche!
🔒 Segurança no Remoting +20 XP ▾
Princípio do menor privilégio: use contas dedicadas para gerenciamento remoto com apenas as permissões necessárias.
Use HTTPS em vez de HTTP para criptografar o tráfego em redes não confiáveis.
Audite conexões remotas nos logs de eventos: Get-WinEvent -LogName 'Microsoft-Windows-WinRM/Operational'
⚠️ Cuidado: nunca use credenciais de Administrador de Domínio para tarefas rotineiras. Crie contas específicas para scripts automatizados.
