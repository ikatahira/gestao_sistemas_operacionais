📁 1. O Explorador de Arquivos +20 XP ▼

Interface do Explorador de Arquivos do Windows 11

🪟
Abra rápido com Win + E. O painel esquerdo mostra a árvore de diretórios, o direito mostra o conteúdo da pasta selecionada.
🔧
A barra de ferramentas do Windows 11 foi redesenhada: Novo, Recortar, Copiar, Colar, Renomear, Excluir, Classificar e Visualizar — tudo ali em cima.
📌
Use Acesso Rápido (no painel esquerdo) para fixar as pastas que você usa com mais frequência.
Win+EAbrir Explorador
Alt+↑Pasta acima
Alt+←Voltar
F5Atualizar
💡

Dica pro: Clique na barra de endereço e digite um caminho direto (ex: C:\Windows\System32) para navegar instantaneamente sem usar o mouse.

🏷️ 2. Atributos de Arquivos +20 XP ▼

Os 4 atributos principais de arquivos no Windows

🔍
Para ver arquivos ocultos: Explorador → Ver → Mostrar → Itens Ocultos. Uma caixinha de seleção simples!
⚙️
Para ver arquivos de sistema: Explorador → Opções → Exibir → desmarque "Ocultar arquivos protegidos do sistema operacional".
⚠️

Cuidado: Arquivos com atributo Sistema são críticos para o Windows funcionar. Modifique-os somente se souber exatamente o que está fazendo!

🗂️ 3. Organização Profissional de Pastas +20 XP ▼

Comparação: organização ruim vs. organização profissional

📅
Use datas no formato AAAA-MM-DD (ex: 2026-03-11). Assim os arquivos ficam ordenados cronologicamente de forma automática!
🚫
Evite acentos e espaços em nomes de pastas e arquivos quando for trabalhar com programação ou linha de comando. Use underline (_) ou hífen (-).
📏
Mantenha no máximo 4-5 níveis de subpastas. Mais que isso dificulta a navegação e aumenta a chance de errar o caminho.
🏆

Regra de ouro: Uma pessoa que nunca viu seus arquivos deve conseguir encontrar qualquer coisa em menos de 30 segundos.

🔍 4. Pesquisa Avançada no Windows +20 XP ▼

Pesquisa avançada com filtros na barra do Explorador

📂
Filtros úteis na barra de pesquisa:
tipo:*.pdfbusca PDFs
data:>2025após 2025
tamanho:>10MBacima de 10MB
nome:relatorio*começa com...
⚡
A busca indexada é muito mais rápida. Configure em: Painel de Controle → Opções de Indexação. Adicione as pastas que você mais usa!
💡

Truque: Pesquise diretamente pelo menu Iniciar pressionando Win e digitando o nome do arquivo. O Windows encontra em milissegundos!
