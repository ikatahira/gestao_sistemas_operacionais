📂 1. Gerenciamento de Arquivos com PowerShell +20 XP ▼

PowerShell é MUITO poderoso para arquivos — o que levaria horas no Explorador, leva segundos aqui!

📋
Get-ChildItem → lista arquivos e pastas (equivalente ao dir/ls)
🆕
New-Item -ItemType Directory "Pasta" → cria pasta
📄
Copy-Item "orig.txt" "dest.txt" → copia arquivo
✂️
Move-Item "arquivo.txt" "C:\Nova\" → move arquivo
🗑️
Remove-Item "arquivo.txt" → deleta arquivo
⚡

Poder real: Get-ChildItem *.txt | Remove-Item → deleta TODOS os arquivos .txt de uma vez!

🔗 2. O Pipeline: O Coração do PowerShell +20 XP ▼

O pipeline (|) conecta a saída de um cmdlet à entrada do próximo. É incrivelmente poderoso!

📖
Leia o pipeline da esquerda para a direita: "pega → filtra → ordena → mostra"
# Exemplo: processos que consomem mais CPU
Get-Process | Where-Object {$_.CPU -gt 10} |
  Sort-Object CPU | Select-Object Name, CPU
🎯
Leitura: "Pega processos → filtra os com CPU > 10 → ordena por CPU → mostra só Nome e CPU"
💡

$_ é a variável especial que representa o objeto atual dentro do pipeline. É muito importante memorizar isso!

🔎 3. Filtragem e Formatação de Saídas +20 XP ▼

Três cmdlets essenciais para trabalhar com saídas:

🔍
Where-Object: filtra objetos por condição: Get-Service | Where-Object {$_.Status -eq 'Running'}
📋
Select-Object: escolhe quais propriedades mostrar: Get-Process | Select-Object Name, CPU, Id
📊
Sort-Object: ordena resultados: Get-ChildItem | Sort-Object Length -Descending (arquivos maiores primeiro)
💾
Export-Csv: exporta DIRETO para Excel! Get-Process | Export-Csv processos.csv
📊 4. Variáveis no PowerShell +20 XP ▼

Variáveis começam sempre com $ — fácil de reconhecer!

📦
Armazena qualquer coisa: $nome = "João", $numero = 42, $procs = Get-Process
♻️
Reutilize depois: $procs | Where-Object {$_.CPU -gt 5}
⭐
$_ representa o objeto atual dentro de pipes e laços. Vai usar isso O TEMPO TODO!
📋
$PSVersionTable mostra a versão do PowerShell. $HOME mostra o diretório do usuário.
🚀

Desafio: $arquivos = Get-ChildItem C:\ e depois $arquivos.Count — quantos itens há em C:\?
