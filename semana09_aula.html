🔗 O Pipe | — O Coração do PowerShell +20 XP ▾
O pipe | conecta cmdlets em cadeia: a saída do da esquerda vira a entrada do da direita.
No PowerShell, passa objetos, não texto simples — cada item tem propriedades como .Name, .CPU, .Status.
Você pode encadear quantos cmdlets quiser — como uma linha de montagem.
Get-Process
→
Where-Object
→
Sort-Object
→
Select-Object
→
resultado
💡
Use o acento grave ` para quebrar uma linha longa em várias — o PowerShell entende que a instrução continua na linha seguinte.
COMANDO Pipeline básico — processos com mais de 10s de CPU
# Exemplo 1 — pipeline simples
PS C:\> Get-Process | Where-Object { $_.CPU -gt 10 }
Saída no terminal
NPM(K) PM(M) WS(M) CPU(s) Id ProcessName
------ ----- ------ ------ -- -----------
248 512.3 480.1 142.8 4120 chrome
64 198.5 220.4 89.2 2380 Code
32 88.1 102.3 24.7 1844 powershell
12 45.2 62.8 18.3 3100 Teams
COMANDO Pipeline completo — top 5 processos por CPU com colunas específicas
PS C:\> Get-Process `
  | Where-Object { $_.CPU -gt 5 } `
  | Sort-Object CPU -Descending `
  | Select-Object Name, CPU, Id `
  | Select-Object -First 5
Saída no terminal — apenas 5 linhas, só as colunas que você pediu

---- --- --

Code 89.2 2380

🔍 Filtragem — Where-Object e Operadores +20 XP ▾
Where-Object filtra objetos. Dentro do bloco {}, use $_ para representar cada item.
Operadores: -eq igual · -ne diferente · -gt maior · -lt menor · -like padrão com * · -match regex
Sintaxe curta: Where CPU -gt 100 (sem $_.) — disponível no PowerShell 3+.
COMANDO Serviços ativos — filtro por Status
PS C:\> Get-Service | Where-Object { $_.Status -eq 'Running' }

📊 Sort · Select · Export — Apresentando Dados +20 XP ▾
Sort-Object ordena resultados por qualquer propriedade. -Descending inverte a ordem.
Select-Object escolhe quais propriedades exibir. -First 5 pega os 5 primeiros.
Export-Csv exporta diretamente para Excel! -NoTypeInformation remove a linha técnica do cabeçalho.
COMANDO Top 5 processos que mais consomem RAM
PS C:\> Get-Process `
  | Sort-Object WorkingSet -Descending `
  | Select-Object -First 5 Name, @{N='RAM(MB)';E={[math]::Round($_.WorkingSet/1MB,1)}}
Saída — coluna personalizada RAM(MB)
Name RAM(MB)
---- -------

powershell 62.8

📦 Variáveis e a Variável Especial $_ +20 XP ▾
Variáveis começam com $. Armazenam qualquer coisa: texto, número, lista de objetos ou resultado de cmdlet.
$_ (ou $PSItem) representa o objeto atual dentro de um pipe ou laço. Você vai usar isso o tempo todo!
Variáveis automáticas: $env:COMPUTERNAME (nome do PC), $env:USERNAME (usuário), $PSVersionTable (versão do PS).
COMANDO Armazenar resultado em variável e reutilizar
PS C:\> $processos = Get-Process
PS C:\> $processos.Count # quantos processos?
Saída — total de processos em execução
87

# Agora filtramos da variável — sem precisar chamar Get-Process de novo!
COMANDO Reutilizar a variável no pipeline
PS C:\> $processos | Where-Object { $_.CPU -gt 5 }
Saída — mesmos dados, novo filtro, sem nova consulta ao SO
NPM(K) PM(M) WS(M) CPU(s) Id ProcessName
------ ----- ----- ------ -- -----------
248 512.3 480.1 142.8 4120 chrome
64 198.5 220.4 89.2 2380 Code
COMANDO Variáveis de ambiente — informações do sistema
PS C:\> Write-Host "Computador: $env:COMPUTERNAME"
PS C:\> Write-Host "Usuário: $env:USERNAME"
Saída — dados reais do seu computador
Computador: DESKTOP-LAB01
Usuário: aluno.gso
COMANDO Espaço livre no disco C: em GB
PS C:\> $disco = (Get-PSDrive C).Free / 1GB
PS C:\> Write-Host "Espaço livre: $([math]::Round($disco,1)) GB"
Saída — espaço livre calculado automaticamente
Espaço livre: 127.4 GB
⚡
Desafio: rode $arquivos = Get-ChildItem C:\ e depois $arquivos.Count — quantos itens existem na raiz do C:\?
🗺️ Navegação e Atalhos Essenciais +20 XP ▾
Set-Location (alias cd) muda o diretório. Get-Location (alias pwd) mostra onde você está.
Get-ChildItem (alias ls ou dir) lista o conteúdo. -Recurse entra em subpastas. -Filter *.txt filtra por extensão.
Atalhos de teclado: ↑↓ histórico · Tab autocompletar · Ctrl+C cancelar execução.
COMANDO Navegar pelo sistema de arquivos
PS C:\> Set-Location 'C:\Windows' # ou: cd C:\Windows
PS C:\Windows> Get-Location # ou: pwd
Saída — prompt muda para refletir a pasta atual
Path
----
C:\Windows

PS C:\Windows> Get-ChildItem # conteúdo atual
PS C:\Windows> Get-ChildItem -Filter *.log # só .log
