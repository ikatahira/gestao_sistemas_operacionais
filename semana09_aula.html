🔗 O Pipe | — O Coração do PowerShell +20 XP ▾
O pipe | conecta cmdlets em cadeia: a saída do da esquerda vira a entrada do da direita. No PowerShell, passa objetos, não texto.
Você pode encadear quantos cmdlets quiser. Cada um processa e passa adiante — como uma linha de montagem.
Get-Process
|
Where-Object
|
Sort-Object
|
Select-Object
→
resultado
# Pipeline simples: processos acima de 10s de CPU Get-Process | Where-Object {$_.CPU -gt 10} # Pipeline completo: top 5 processos, colunas específicas Get-Process ` | Where-Object {$_.CPU -gt 5} ` | Sort-Object CPU -Descending ` | Select-Object Name, CPU, Id ` | Select-Object -First 5
💡 Dica: use o acento grave ` para quebrar uma linha longa em várias — o PowerShell entende que a instrução continua.
🔍 Filtragem — Where-Object e Operadores +20 XP ▾
Where-Object filtra objetos de uma coleção. Dentro do bloco {}, use $_ para representar cada item.
Operadores: -eq igual · -ne diferente · -gt maior · -lt menor · -like padrão com * · -match regex.
Sintaxe curta: Where CPU -gt 100 (sem $_.) — disponível no PowerShell 3+.
# Serviços em execução Get-Service | Where-Object {$_.Status -eq 'Running'} # Processos pesados — sintaxe curta Get-Process | Where-Object CPU -gt 100 # Arquivos .log na pasta Windows Get-ChildItem 'C:\Windows' | Where-Object {$_.Extension -eq '.log'} # Filtrar por nome com padrão Get-Service | Where-Object {$_.Name -like 'W*'}
📊 Sort · Select · Export — Apresentando Dados +20 XP ▾
Sort-Object ordena resultados por qualquer propriedade. -Descending inverte a ordem.
Select-Object escolhe quais propriedades exibir. -First 5 pega os 5 primeiros. -Last 3 pega os últimos.
Export-Csv exporta diretamente para Excel! -NoTypeInformation remove a linha de cabeçalho técnico.
# Top 5 processos por RAM Get-Process ` | Sort-Object WorkingSet -Descending ` | Select-Object -First 5 Name, @{N='RAM(MB)';E={[math]::Round($_.WorkingSet/1MB,1)}} # Exportar lista de serviços para Excel Get-Service ` | Select-Object Name, DisplayName, Status ` | Export-Csv 'C:\servicos.csv' -NoTypeInformation # Salvar em arquivo de texto Get-Process | Out-File 'C:\processos.txt'
🚀 Resultado imediato: rode Get-Service | Export-Csv "C:\servicos.csv" e abra o arquivo no Excel — você criou um relatório profissional em 1 linha!
📦 Variáveis e a Variável Especial $_ +20 XP ▾
Variáveis começam sempre com $. Armazenam qualquer coisa: texto, número, lista de objetos ou resultado de cmdlet.
$_ (ou $PSItem) representa o objeto atual dentro de um pipe ou laço. Você vai usar isso o tempo todo!
Variáveis automáticas úteis: $env:COMPUTERNAME (nome do PC), $env:USERNAME (usuário), $PSVersionTable (versão do PS).
# Armazenar resultado em variável $processos = Get-Process $processos.Count # quantos processos? # Reutilizar a variável $processos | Where-Object {$_.CPU -gt 5} # Variáveis de ambiente Write-Host "Computador: $env:COMPUTERNAME" Write-Host "Usuário: $env:USERNAME" # Operações matemáticas $disco = (Get-PSDrive C).Free / 1GB Write-Host "Espaço livre: $([math]::Round($disco,1)) GB"
⚡ Desafio: rode $arquivos = Get-ChildItem C:\ e depois $arquivos.Count — quantos itens existem na raiz do C:\?
🗺️ Navegação e Atalhos Essenciais +20 XP ▾
Set-Location (alias cd) muda o diretório. Get-Location (alias pwd) mostra onde você está.
Get-ChildItem (alias ls ou dir) lista o conteúdo. -Recurse entra em subpastas. -Filter *.txt filtra por extensão.
# Navegar pelo sistema de arquivos Set-Location 'C:\Windows' # ou: cd C:\Windows Get-Location # ou: pwd # Listar arquivos Get-ChildItem # conteúdo atual Get-ChildItem -Filter *.log # só .log Get-ChildItem -Recurse -Filter *.exe | Select-Object FullName # Atalhos de teclado no terminal # ↑↓ — histórico de comandos # Tab — autocompletar # Ctrl+C — cancelar execução
⌨️ Alias: cd, ls, dir, cat, cp, mv, rm — todos funcionam no PowerShell! Quem vem do CMD ou do Linux se sente em casa.
