🚀 1. Menu Iniciar do Windows 11 +20 XP ▼

O novo menu Iniciar do Windows 11 é centralizado e simplificado. Contém: Apps fixados (você personaliza!), Apps recomendados (baseado no uso recente) e campo de pesquisa.

📌
Clique com botão direito em qualquer app → 'Fixar no Início' para adicioná-lo.
👁️
Clique em 'Todos os apps' para ver a lista completa de programas instalados.
🏢
Em empresas, o menu Iniciar pode ser configurado e bloqueado via Política de Grupo (GPO).
WinAbre/fecha menu
Win + QPesquisa direta
💡

Dica: Organize os apps fixados em grupos! Clique direito em um grupo e escolha "Nomear grupo".

🖥️ 2. Configuração Multi-Monitor +20 XP ▼

Dois monitores = dobro de produtividade! No Windows: Configurações → Sistema → Tela.

🔲
Estender tela: área de trabalho ocupa os dois monitores. Perfeito para trabalhar!
📺
Duplicar tela: mesma imagem nos dois monitores. Ideal para apresentações com projetor.
1️⃣
Mostrar apenas em um: útil quando você quer focar só em um monitor ou economizar energia.
Win + POpções de projeção
⚡

Atalho rápido: Win + P abre o painel de projeção instantaneamente — sem precisar ir em Configurações!

🔔 3. Central de Ações e Notificações +20 XP ▼

A Central de Ações fica no canto direito da barra de tarefas (ícone de sino + relógio).

📱
Traz controles rápidos: Wi-Fi, Bluetooth, Modo Avião, Brilho, Volume, Foco, VPN...
🔕
Configure notificações em: Configurações → Sistema → Notificações. Você pode silenciar app por app!
🎯
Foco/Modo não Perturbe: bloqueia notificações por um período — ótimo durante provas ou trabalho concentrado.
Win + AAbre Central de Ações
Win + NCentral de notificações
👤 4. Contas de Usuário no Windows +20 XP ▼

O Windows suporta múltiplos tipos de conta. Entender a diferença é fundamental no suporte técnico!

👑
Administrador: controle total do sistema. Pode instalar programas, alterar configurações de sistema.
👤
Usuário Padrão: uso normal do dia a dia, sem instalar programas. Mais seguro para usuários finais!
☁️
Conta Microsoft: sincroniza configurações com a nuvem (temas, senhas, etc).
🔒
Conta Local: sem internet, mais privada. Ideal para ambientes corporativos com restrições.
🏢

No trabalho real: sempre crie contas Usuário Padrão para usuários finais. Isso protege o sistema de modificações acidentais!
