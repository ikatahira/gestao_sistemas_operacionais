SEÇÃO A — Introdução ao SO & Arquitetura Interna (Q01–Q08)
Questão 01 · Conceito SO
B) Intermediar usuário e hardware
O SO gerencia CPU, RAM, armazenamento e periféricos — é o "gerente" entre você e o hardware.
Questão 02 · Tipos de SO
C) Microsoft Word
O Word é um aplicativo que roda DENTRO de um SO. SOs: Windows, Android, macOS, Linux.
Questão 03 · Kernel Mode
B) Tela Azul da Morte (BSOD)
Erro no Kernel = sistema inteiro trava. Kernel tem acesso total ao hardware — sem ele, nada funciona.
Questão 04 · User Mode
B) Roda em User Mode, isolado do Kernel
Aplicativos rodam em User Mode com acesso restrito. Se travam, não afetam o Kernel.
Questão 05 · Processos
B) Número único que identifica o processo
PID = Process ID. Cada processo em execução recebe um número único. Ver em Gerenciador de Tarefas → Detalhes.
Questão 06 · Estados
C) Bloqueado / Aguardando
Processo aguardando evento externo (rede, disco, input) = Bloqueado. Não consome CPU enquanto espera.
Questão 07 · Memória Virtual
C) Memória virtual (paginação no disco)
Quando a RAM enche, o SO usa um arquivo de paginação no HD/SSD como extensão da memória.
Questão 08 · Gerenciador
B) Ctrl + Shift + Esc
Ctrl+Shift+Esc abre o Gerenciador diretamente. Ctrl+Alt+Del abre um menu intermediário.
SEÇÃO B — Interface & Atalhos do Windows 11 (Q09–Q16)
Questão 09 · Barra de Tarefas
B) Centralizado
Win 11 centralizou o Iniciar. Pode ser movido para a esquerda em Configurações → Barra de Tarefas.
Questão 10 · Snap Layouts
B) Mouse sobre o botão Maximizar
Passar o mouse sobre ⬜ revela o menu de Snap Layouts. Ou use Win + ← / →.
Questão 11 · Win + D
B) Mostra/oculta a área de trabalho
Win+D minimiza todas as janelas mostrando a área de trabalho. Pressionar novamente restaura.
Questão 12 · Snap Esquerda
C) Win + ←
Win+← encaixa à esquerda. Win+→ encaixa à direita. Win+↑ maximiza.
Questão 13 · Central de Ações
B) Central de Ações (rede/volume/bateria)
No Win 11, notificações e ações rápidas foram separadas. Wi-Fi/Bluetooth ficam na Central de Ações.
Questão 14 · Contas de Usuário
B) Adm instala/configura; Padrão tem acesso restrito
Administrador tem controle total. Usuário Padrão é mais seguro para uso cotidiano.
Questão 15 · Menu Iniciar
B) Clicar em "Todos os apps"
No Win 11 o Iniciar mostra apps fixados por padrão. "Todos os apps" lista todos instalados.
Questão 16 · Ícones Área de Trabalho
B) Personalizar → Temas → Config. de ícones
Caminho: Clicar direito na Área de Trabalho → Personalizar → Temas → Configurações de ícones da área de trabalho.
SEÇÃO C — Gerenciamento de Arquivos & Pastas (Q17–Q20)
Questão 17 · Explorador
A) Win + E
Win+E abre o Explorador de Arquivos instantaneamente. Atalho essencial para técnicos.
Questão 18 · Atributo Sistema
C) Arquivo crítico do SO
Atributo Sistema = arquivo usado pelo Windows para funcionar. Modificar pode tornar o SO instável.
Questão 19 · Copiar vs Mover
B) Movido — original some da origem
Arrastar no mesmo disco = Mover. Arrastar entre discos diferentes = Copiar. Ctrl arrasta = sempre copia.
Questão 20 · Lixeira & NTFS
B) Shift+Delete exclui sem passar pela Lixeira
Pendrive/rede → sem Lixeira (A e D erradas)  |  Lixeira tem tamanho limitado (C errada)  |  Shift+Delete = exclusão permanente ✓
