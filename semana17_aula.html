🔄 Parte 1 — Windows Update
Por que atualizar? CONCEITO
⚠️
Dado real: 60% dos ataques bem-sucedidos exploram vulnerabilidades que já possuíam patch disponível. Manter o Windows atualizado é a medida de segurança mais simples e eficaz.
Tipo de AtualizaçãoO que é?Urgência
SegurançaCorrige falhas que podem ser exploradas por hackersCRÍTICO — instale logo
QualidadeCorrige bugs e problemas de estabilidadeRecomendado
RecursosAdiciona novas funcionalidades ao WindowsPode aguardar
DriverAtualiza drivers de hardware pelo Windows UpdateAvalie antes
Passo a passo: Configurando o Windows Update PRÁTICA
1

Abrir as Configurações de Atualização

Pressione Win + I → clique em Windows Update. Ou abra o menu Iniciar, digite "Windows Update" e pressione Enter.

⚙️ Configurações › Windows Update
Verificar AtualizaçõesÚltima verificação: hoje às 08:32
✓ Atualizado
Reinicialização ativaDas 22h às 06h — o PC não reinicia nesse horário
Atualizações opcionaisDrivers e outras atualizações
2 disponíveis
Pausar atualizaçõesBloquear por até 5 semanas
2

Configurar Opções Avançadas

Em Opções Avançadas, você pode ativar: Receber atualizações para outros produtos Microsoft (recomendado), Baixar por conexão limitada (desativar para não gastar dados), e configurar a Reinicialização ativa com seus horários de trabalho.

💡
Dica corporativa: Em empresas com muitos PCs, o WSUS (Windows Server Update Services) centraliza aprovação e distribuição das atualizações. Os PCs buscam updates no servidor interno, não na Microsoft diretamente.
3

Verificar via PowerShell (conexão com aula anterior!)

Use o PowerShell para listar os hotfixes instalados e verificar datas:

PowerShell (Administrador)
# Listar as últimas 10 atualizações instaladas
PS> Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 10

# Saída:
HotFixID Description InstalledOn
-------- ----------- -----------
KB5035853 Security Update 01/05/2026
KB5034441 Security Update 15/04/2026
KB5033375 Update 10/04/2026

# Verificar se há atualizações pendentes
PS> (New-Object -ComObject Microsoft.Update.Session).CreateUpdateSearcher().Search("IsInstalled=0").Updates.Count
📝 Parte 2 — Editor de Registro (regedit)
🚨
ATENÇÃO — Leia antes de continuar: O Registro é o banco de dados do coração do Windows. Alterações erradas podem inutilizar o sistema completamente. Sempre faça backup antes de qualquer mudança.
Estrutura do Registro CONCEITO
Chave Raiz (Hive)O que armazena
HKEY_LOCAL_MACHINE (HKLM)Configurações do sistema e hardware — valem para TODOS os usuários
HKEY_CURRENT_USER (HKCU)Configurações do usuário logado atualmente
HKEY_CLASSES_ROOT (HKCR)Associações de arquivos e extensões
HKEY_USERS (HKU)Configurações de todos os perfis de usuário
HKEY_CURRENT_CONFIG (HKCC)Configurações de hardware atual
Passo a passo SEGURO no Registro PRÁTICA
1

🔒 SEMPRE: Fazer backup antes

Pressione Win + R → digite regedit → Enter. Na janela do Editor, clique em Arquivo → Exportar. Escolha "Tudo" em "Intervalo de exportação" e salve em local seguro (ex: Desktop ou pendrive).

✅
Um backup do registro gera um arquivo .reg que pode ser restaurado com duplo clique. Nunca pule essa etapa!
2

Navegar e Entender a Estrutura

O Registro é organizado como uma árvore de pastas. Cada "pasta" é uma Chave. Dentro das chaves existem Valores (como arquivos). Exemplo prático — veja como fica:

📝 regedit — Editor do Registro
▼ HKEY_LOCAL_MACHINE
▼ SOFTWARE
▼ Microsoft
▼ Windows
▶ CurrentVersion
▶ WindowsUpdate

; No painel direito (valores da chave selecionada):
ProductName = "Windows 11 Pro"
CurrentBuild = "26100"
RegisteredOrganization = "SENAI"
3

Exemplo prático: Desativar início automático de um programa

Uma das edições mais comuns é remover programas que iniciam com o Windows via Registro:

Caminho no regedit
HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

; Aqui ficam os programas que abrem com o Windows
; do usuário atual. Para TODOS os usuários, use:
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

; Via PowerShell (mais seguro!):
PS> Get-ItemProperty "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
💡
Dica pro: Prefira usar o Gerenciador de Tarefas (aba Inicialização) ou o msconfig para gerenciar programas de inicialização. Reserve o regedit para edições que só podem ser feitas por ele.
🛡️ Parte 3 — Windows Defender
Verificar status completo via PowerShell PRÁTICA
1

Comando essencial: Get-MpComputerStatus

Este comando retorna o status completo do Windows Defender — muito mais útil que a interface gráfica para diagnóstico rápido:

PowerShell (Administrador)
PS> Get-MpComputerStatus | Select-Object `
RealTimeProtectionEnabled, `
AntivirusEnabled, `
AntispywareEnabled, `
AntivirusSignatureLastUpdated, `
QuickScanAge

# Saída esperada em PC saudável:
RealTimeProtectionEnabled : True
AntivirusEnabled : True
AntispywareEnabled : True
AntivirusSignatureLastUpdated: 25/05/2026 06:00:00
QuickScanAge : 5 ← ideal é < 7 dias
2

Iniciar uma varredura completa via PowerShell

PowerShell (Administrador)
# Varredura rápida
PS> Start-MpScan -ScanType QuickScan

# Varredura completa (demora mais, mais completo)
PS> Start-MpScan -ScanType FullScan

# Atualizar definições de vírus
PS> Update-MpSignature
3

🔐 Parte 4 — Políticas de Segurança Local (secpol.msc)
Acessar e configurar PRÁTICA
1

Abrir o Editor de Política de Segurança Local

Pressione Win + R → digite secpol.msc → Enter. Disponível apenas no Windows Pro, Enterprise e Education.

💡
No Windows Home, use o gpedit.msc para o Editor de Política de Grupo, mas algumas opções de segurança ficam restritas.
2

Política de Senha: Configurações essenciais

Acesse Políticas de Conta → Política de Senha. Configurações recomendadas para ambiente corporativo:

PolíticaValor RecomendadoPor quê?
Comprimento mínimo de senha12 caracteresDificulta ataques de força bruta
Senha deve satisfazer complexidadeHabilitadoExige letras, números e símbolos
Duração máxima da senha90 diasTroca periódica reduz exposição
Histórico de senhas10 senhas lembradasImpede reutilização imediata
3

Política de Bloqueio de Conta

Em Política de Bloqueio de Conta, configure:

5 tentativas

🔬 Atividades Práticas

Acesse o Guia de Exercícios para rubricas e resoluções detalhadas.

1
Configurando o Windows Update
⏱ 30 min🔬 LaboratórioPowerShell
Configure o Windows Update para uso corporativo e use Get-HotFix no PowerShell para gerar um relatório das últimas 20 atualizações instaladas, salvando em CSV.
  • Configure a Reinicialização Ativa para o horário de funcionamento
  • Ative recebimento de atualizações para outros produtos Microsoft
  • Execute Get-HotFix | Export-Csv C:\relatorio_updates.csv
  • Verifique o arquivo gerado e documente as 5 últimas atualizações
2
Explorando o Registro com Segurança
⏱ 35 min🔬 Laboratórioregedit
Explore o Editor de Registro fazendo backup, navegando pela estrutura e localizando chaves relevantes — sem fazer alterações sem supervisão.
  • Exporte um backup completo do Registro (Arquivo → Exportar → Tudo)
  • Navegue até HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion
  • Documente o valor de ProductName e CurrentBuild
  • Repita via PowerShell: Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion"
3
Políticas de Segurança e Windows Defender
⏱ 25 min🔬 Laboratóriosecpol.msc
Configure políticas de senha no secpol.msc e verifique o status do Defender via PowerShell, gerando um relatório de saúde de segurança do sistema.
  • Abra o secpol.msc e documente as políticas de senha atuais
  • Configure comprimento mínimo de senha para 12 caracteres
  • Execute Get-MpComputerStatus e salve o resultado
  • Verifique se as definições de vírus estão atualizadas
