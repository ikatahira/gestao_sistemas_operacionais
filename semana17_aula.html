🔄 Windows Update e Estratégias de Atualização

Manter o Windows atualizado é a medida de segurança mais importante. Tipos de atualização: Segurança (críticas — instale sempre), Qualidade (correções de bugs), Recursos (novas funcionalidades — pode atrasar). Em empresas, as atualizações são controladas pelo WSUS (Windows Server Update Services) — o admin aprova e distribui as atualizações para os PCs da rede de forma centralizada.

📝 Editor de Registro (regedit)

O Registro do Windows é o banco de dados central que armazena todas as configurações do sistema e aplicativos. CUIDADO: alterar o registro incorretamente pode tornar o sistema inoperante. Sempre: faça backup antes (Arquivo → Exportar), documente o que vai alterar, teste em ambiente controlado primeiro. Estrutura: HKEY_LOCAL_MACHINE (configurações do sistema), HKEY_CURRENT_USER (configurações do usuário atual).

🛡️ Windows Defender e Segurança

O Windows Defender (Segurança do Windows) é o antivírus e antimalware nativo. Inclui: proteção em tempo real, firewall, controle de aplicativos, proteção de contas. Para técnicos: conheça como verificar o status via PowerShell (Get-MpComputerStatus), como excluir pastas da verificação (para softwares corporativos legítimos), e como fazer uma verificação completa manual.

🔐 Políticas de Segurança Local

O Editor de Política de Segurança Local (secpol.msc) permite configurar regras de segurança para o computador local: complexidade de senha, bloqueio de conta após tentativas erradas, auditoria de eventos, direitos do usuário. Em domínios corporativos, essas políticas são definidas centralmente via GPO (Group Policy Object) pelo administrador de domínio.
