O técnico precisa criar uma estrutura de pastas padronizada para guardar todos os registros de atendimento da empresa.

Crie a estrutura de pastas da empresa no PowerShell
Execute o comando abaixo para criar todas as pastas de uma só vez
Comando
# Cria estrutura de pastas no Desktop
$base = "$env:USERPROFILE\Desktop\TechSupport"
New-Item -ItemType Directory -Path "$base\Chamados\Abertos" -Force
New-Item -ItemType Directory -Path "$base\Chamados\Concluidos" -Force
New-Item -ItemType Directory -Path "$base\Documentacao" -Force
New-Item -ItemType Directory -Path "$base\Prints" -Force
Write-Host "Pastas criadas com sucesso!" -ForegroundColor Green
Confirme que as pastas foram criadas
Liste o conteúdo da pasta TechSupport
Comando
Get-ChildItem "$env:USERPROFILE\Desktop\TechSupport" -Recurse
Abra a pasta no Explorador de Arquivos e confirme visualmente
No Explorer, navegue até Desktop → TechSupport. Você deve ver as 4 subpastas.
Verificar

Win + Shift + S, selecione a janela do Explorer com todas as pastas visíveis

A empresa precisa de uma conta separada para o técnico de campo. Vamos criar o usuário tecnico.campo no sistema.

Crie o usuário "tecnico.campo"

O cliente reclamou que o computador está lento. Vamos verificar o uso de CPU e RAM para diagnosticar o problema.

Verifique os 5 processos que mais consomem CPU
Identifique se há algum processo suspeito ou pesado
Comando
# Top 5 processos por uso de CPU
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name, CPU, WorkingSet
Veja o uso total de memória RAM
Quanto de RAM está livre vs. em uso
Comando
# Uso de memória RAM em GB
$os = Get-CimInstance Win32_OperatingSystem
$total = [math]::Round($os.TotalVisibleMemorySize / 1MB, 2)
$livre = [math]::Round($os.FreePhysicalMemory / 1MB, 2)
$uso = [math]::Round($total - $livre, 2)
Write-Host "RAM Total: $total GB | Em uso: $uso GB | Livre: $livre GB"
Abra o Gerenciador de Tarefas e confirme os dados
Ctrl + Shift + Esc → aba "Desempenho" → compare CPU e Memória com o que o PowerShell mostrou
Verificar
Tire um print do Gerenciador de Tarefas aberto na aba Desempenho
Deve mostrar os gráficos de CPU e Memória em tempo real

Checklist final e documentação
0 / 4 tarefas
✓ Concluída

Todo atendimento precisa ser documentado. Vamos criar o arquivo de registro do atendimento de hoje.

Crie o arquivo de registro do atendimento
O arquivo será salvo automaticamente na pasta Documentacao que criamos na Missão 2
Comando
# Cria o registro do atendimento
$arquivo = "$env:USERPROFILE\Desktop\TechSupport\Documentacao\atendimento.txt"
$conteudo = @"
========================================
REGISTRO DE ATENDIMENTO — TECHSUPPORT
========================================
Data: $(Get-Date -Format "dd/MM/yyyy HH:mm")
Técnico: $(whoami)
Computador: $(hostname)
----------------------------------------
ATIVIDADES REALIZADAS:
[ ] Reconhecimento do equipamento
[ ] Organização de pastas
[ ] Criação de usuário tecnico.campo
[ ] Verificação de desempenho
========================================
"@
$conteudo | Out-File -FilePath $arquivo -Encoding UTF8
Write-Host "Arquivo criado!" -ForegroundColor Cyan
notepad $arquivo
No Bloco de Notas, marque as atividades que realizou com [X]
Troque [ ] por [X] nas atividades que você completou hoje. Salve o arquivo (Ctrl + S).
Editar

Abra o Explorer, vá até a pasta Downloads ou Área de Trabalho, mova os prints capturados para Desktop\TechSupport\Prints
Organizar
